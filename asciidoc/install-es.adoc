= Guía de instalación

== Requisitos

Para comenzar, asegúrese de que las siguientes herramientas estén instaladas en su máquina:

* *Java* (JDK 25 ...)
* *Git*
* https://github.com/unoconv/unoserver[unoserver]

=== Instalar los requisitos previos

==== macOS (Homebrew)

.Instalar JDK 24 y Git usando Homebrew
[source,bash]
----
$ brew install openjdk@25
$ brew install git
----

==== Windows (Winget)

.Instalar JDK 25 y Git usando Winget
[source,bash]
----
winget install --id Microsoft.OpenJDK.25
winget install --id Git.Git
----

== Clonar la intranet lista para el desarrollo

.Clone el repositorio inicial:

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
----

Este repositorio incluye un esqueleto mínimo de intranet (gestión de usuarios Crew + *plugin Spring Security*) listo para el desarrollo.


== Iniciar su intranet

.Navegue dentro de la carpeta de la intranet recién clonada e inicie el servidor:

[source,bash]
----
$ cd intranet
$ ./gradlew server:bootRun
----

[NOTE]
====
El comando `./gradlew` utiliza el Gradle Wrapper, por lo que no necesita instalar Gradle manualmente.
====

.Una vez finalizada la compilación, debería ver:
[source,bash]
----
Grails application running at http://localhost:9442
----

Para cambiar la contraseña de administrador predeterminada, edite los siguientes archivos:

* `server/grails-app/conf/application.yml`
* `server/grails-app/conf/application-MACOSX.yml`

Busque la línea:
[source,yaml]
taack.admin.password: ChangeIt

Después de realizar el cambio, elimine el archivo `intranetDb.mv.db` para aplicar la nueva contraseña.


[NOTE]
====
`application-MACOSX.yml` solo se utiliza cuando la aplicación detecta un entorno macOS. Si utiliza Linux o Windows, se ignorará.
====

[WARNING]
====
Eliminar el archivo `intranetDb.mv.db` borrará de forma permanente todos los datos almacenados anteriormente.
====




=== Configurar una base de datos persistente

Si desea que los datos sean persistentes, modifique los archivos `server/grails-app/conf/application.yml` y
`server/grails-app/conf/application-MACOSX.yml` para utilizar una base de datos persistente.

.Aquí queremos que H2 persista los datos en un archivo en modo de desarrollo:

[source,yaml]
----
environments:
    development:
        dataSource:
            dbCreate: update        <1>
            url: jdbc:h2:./intranetDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE <2>
----

<1> Modo de creación (consulte la documentación de Grails GORM)
<2> `intranetDb`: raíz del nombre del archivo que contiene los datos

=== Generar un archivo JAR para Tomcat

.Utilice la tarea assemble en lugar de bootRun:

[source,bash]
----
$ ./gradlew server:assemble
----
El archivo JAR ensamblado (p. ej., `server-0.6.jar`) se ubicará en `server/build/libs`.


.Puede desplegarlo en su servidor de producción o probarlo localmente

[source,bash]
----
cd server/build/libs
java -jar server-[version].jar   <1>
----
<1> El número de versión se encuentra en `build.gradle`. El valor predeterminado es 0.6

[TIP]
====
Asegúrese de no estar ejecutando ya la aplicación al iniciar una nueva instancia.
====


== Configurar su IDE


Recomendamos encarecidamente utilizar la última versión de *IntelliJ Ultimate Edition* por su completo soporte para *Groovy* y *Grails*.

=== IntelliJ Ultimate Edition

Recomendamos instalar el *plugin de Taack para IntelliJ*, que puede instalar desde el Marketplace de IntelliJ https://plugins.jetbrains.com/plugin/20792-taackuiastautocomplete[TaackUiASTAutocomplete] o directamente desde el https://github.com/Taack/infra/releases/tag/v0.1[repositorio de código fuente].

Abra el proyecto, vaya a File > Open... y seleccione `intranet/settings.gradle`.

Asegúrese de que Gradle esté utilizando JDK 25:

.Abrir la configuración de Gradle y comprobar la versión del JDK de Gradle
image:install-java25-gradle-select.webp[]

<1> Abrir la configuración de Gradle
<2> Comprobar que la versión de JVM de Gradle sea 25 (el proveedor puede ser cualquiera)

=== Visual Studio Code

Si prefiere Visual Studio Code, recomendamos las siguientes extensiones para utilizar este framework:

* https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack[Extension Pack for Java]
* https://marketplace.visualstudio.com/items?itemName=marlon407.code-groovy[code-groovy]
* https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-gradle[Gradle for Java]
* https://marketplace.visualstudio.com/items?itemName=MellowMarshmallow.groovy[Groovy]

[NOTE]
====
La mayoría de las funciones de Grails y del framework Taack no serán reconocidas por VS Code. Las importaciones, la navegación y la asistencia de código pueden verse limitadas. IntelliJ sigue siendo el IDE preferido para obtener soporte completo.
====
