== From Code to Screen

A form is a few lines of Groovy. Fields are symbols generated from your class (`username_`), so the compiler checks them; constraints become localized error messages.

[.home-split]
--
[source,groovy]
----
def form() {
    DslSampleUser u = new DslSampleUser()
    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            form createForm(u, {
                row {
                    col {
                        section 'User', {
                            field u.username_
                            field u.firstName_
                            field u.lastName_
                        }
                    }
                    col {
                        section 'Details', {
                            field u.age_
                            field u.birthday_
                            field u.city_
                            field u.status_
                            field u.enabled_
                        }
                    }
                }
                formAction this.&saveForm as MC
            })
        }
    })
}
----

== Features

[.home-grid]
--
[.home-card]
====
icon:shield[]

*Security per field*

Objects are displayed and edited according to user rights on *each field*. Links and form actions the user cannot run are hidden automatically.

link:doc/UserGuide/Security.adoc[Security →]
====

[.home-card]
====
icon:file-pdf-o[]

*One DSL, every output*

The same description renders to *HTML*, *PDF*, *Mails* and *CSV*.

link:doc/DSLs/block-printable-dsl.adoc[Printable DSL →]
====

[.home-card]
====
icon:language[]

*Localized, validated*

Labels come from i18n files, validation errors are localized with no extra code.

link:doc/DSLs/form-dsl.adoc#_form_validation[Form validation →]
====

[.home-card]
====
icon:table[]

*Filter, sort, paginate*

Tables and filters without writing queries nor keeping session data.

link:doc/DSLs/filter-table-dsl.adoc[Filter and Table DSL →]
====

[.home-card]
====
icon:search[]

*Full-text search*

Solr indexing of statically typed domain objects, with faceting and ranking. File previews can be extended.

link:more/Search/Search.adoc[Search →]
====

[.home-card]
====
icon:database[]

*JDBC on your model*

Query domain objects with TQL (Taack Query Language) from IntelliJ, DBeaver or LibreOffice Base.

link:more/JDBC/taack-jdbc-driver.adoc[Taack JDBC Driver →]
====

[.home-card]
====
icon:terminal[]

*SSH & SFTP*

A shell UI running inside the server process, and a virtual file system per user, with credentials checked (`taack-ui-ssh` module).

<<ssh_sftp,Screenshots ↓>>
====

[.home-card]
====
icon:code-fork[]

*Git server*

The Intercom app serves Git over SSH: documentation written in Asciidoc is pushed, then rendered.

link:app/Intercom.adoc[Intercom →]
====
