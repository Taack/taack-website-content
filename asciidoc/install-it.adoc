= Guida all'installazione

== Requisiti

Per iniziare, assicurati che i seguenti strumenti siano installati sulla tua macchina:

* *Java* (JDK 25 ...)
* *Git*
* https://github.com/unoconv/unoserver[unoserver]

=== Installare i prerequisiti

==== macOS (Homebrew)

.Installare JDK 24 e Git usando Homebrew
[source,bash]
----
$ brew install openjdk@25
$ brew install git
----

==== Windows (Winget)

.Installare JDK 25 e Git usando Winget
[source,bash]
----
winget install --id Microsoft.OpenJDK.25
winget install --id Git.Git
----

== Clonare l'intranet pronta per lo sviluppo

.Clona il repository iniziale:

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
----

Questo repository include uno scheletro minimale di intranet (gestione utenti Crew + *plugin Spring Security*) pronto per lo sviluppo.


== Avviare la tua intranet

.Entra nella cartella dell'intranet appena clonata e avvia il server:

[source,bash]
----
$ cd intranet
$ ./gradlew server:bootRun
----

[NOTE]
====
Il comando `./gradlew` utilizza il Gradle Wrapper, quindi non è necessario installare Gradle manualmente.
====

.Una volta completata la build, dovresti vedere:
[source,bash]
----
Grails application running at http://localhost:9442
----

Per modificare la password di amministratore predefinita, modifica i seguenti file:

* `server/grails-app/conf/application.yml`
* `server/grails-app/conf/application-MACOSX.yml`

Cerca la riga:
[source,yaml]
taack.admin.password: ChangeIt

Dopo aver effettuato la modifica, elimina il file `intranetDb.mv.db` per applicare la nuova password.


[NOTE]
====
`application-MACOSX.yml` viene utilizzato solo quando l'applicazione rileva un ambiente macOS. Se utilizzi Linux o Windows, verrà ignorato.
====

[WARNING]
====
L'eliminazione del file `intranetDb.mv.db` cancellerà definitivamente tutti i dati memorizzati in precedenza.
====




=== Configurare un database persistente

Se desideri che i dati siano persistenti, modifica i file `server/grails-app/conf/application.yml` e
`server/grails-app/conf/application-MACOSX.yml` per utilizzare un database persistente.

.Qui vogliamo che H2 salvi i dati in un file in modalità di sviluppo:

[source,yaml]
----
environments:
    development:
        dataSource:
            dbCreate: update        <1>
            url: jdbc:h2:./intranetDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE <2>
----

<1> Modalità di creazione (vedi la documentazione di Grails GORM)
<2> `intranetDb`: radice del nome del file contenente i dati

=== Produrre un file JAR per Tomcat

.Usa il task assemble invece di bootRun:

[source,bash]
----
$ ./gradlew server:assemble
----
Il JAR assemblato (ad es., `server-0.6.jar`) si troverà in `server/build/libs`.


.Puoi distribuirlo sul tuo server di produzione o testarlo localmente

[source,bash]
----
cd server/build/libs
java -jar server-[version].jar   <1>
----
<1> Il numero di versione si trova in `build.gradle`. Il valore predefinito è 0.6

[TIP]
====
Assicurati che l'applicazione non sia già in esecuzione quando avvii una nuova istanza.
====


== Configurare il tuo IDE


Consigliamo vivamente di utilizzare l'ultima versione di *IntelliJ Ultimate Edition* per il suo supporto completo a *Groovy* e *Grails*.

=== IntelliJ Ultimate Edition

Consigliamo di installare l'*IntelliJ Taack Plugin*, che puoi installare dall'IntelliJ Marketplace https://plugins.jetbrains.com/plugin/20792-taackuiastautocomplete[TaackUiASTAutocomplete] o direttamente dal https://github.com/Taack/infra/releases/tag/v0.1[repository del codice sorgente].

Apri il progetto, vai su File > Open... e seleziona `intranet/settings.gradle`.

Assicurati che Gradle stia utilizzando il JDK 25:

.Apri le impostazioni di Gradle e verifica la versione del JDK di Gradle
image:install-java25-gradle-select.webp[]

<1> Apri le impostazioni di Gradle
<2> Verifica che la versione della JVM di Gradle sia 25 (il fornitore può essere qualsiasi)

====

====
