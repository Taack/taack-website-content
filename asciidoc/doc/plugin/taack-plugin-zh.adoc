== 注册应用

应用只需注册其 *入口点*（即访问应用时执行的 #动作#）以及对应的 *SVG 图标*。控制器入口点名称用于 `i18n` 属性文件中的本地化标签和描述。

.Crew 应用注册示例
[source,groovy]
----
@PostConstruct
void init() {
TaackAppRegisterService.register TaackApp(          <1>
        CrewController.&index as MC,                <2>
        new String(
            this.class
            .getResourceAsStream("/crew/crew.svg")  <3>
            .readAllBytes())
    )
}

----

<1> 调用静态方法 `TaackAppRegisterService.register`
<2> 定义入口点
<3> SVG 图标

== 国际化（I18n）

在 `i18n` 属性文件中添加：

[source,properties]
----
crew.app=Crew
crew.desc=User Management Application
attachment.app=Attachment
attachment.desc=Global File Manager
----
