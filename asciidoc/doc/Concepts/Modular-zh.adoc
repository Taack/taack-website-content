= 模块化应用开发

https://github.com/Taack/intranet[内联网示例应用] 是一个模块化的 https://gradle.org/[Gradle] 应用。您可以点击此处获取运行说明：link:../../usage-zh.adoc[安装示例内联网]。

== 内联网示例应用目录结构


[plantuml, format="svg", opts="inline", theme="spacelab"]
----
@startsalt
{
{T
+ <&folder> Intranet | Root Directory
++ <&folder> app    | Application Modules Directory
+++ <&folder> crew  | Mandatory base app to manage users
+++ <&folder> appModule1  | First application (Gradle module)
+++ <&folder> appModule2  | Second application
+++ <&folder> ...   | And so on
++ <&folder> buildSrc | Gradle Build Instructions
++ <&folder> server | Server Root Application (Grails app)
++ <&folder> gradle           | Gradle binaries
++ <&file> build.gradle
++ <&file> settings.gradle
++ <&file> gradle.properties
++ <&file> gradlew
}
}
@endsalt
----

=== _app_ 目录

存放组成内联网应用的 Grails 插件（或 Gradle 模块）。这些插件应尽量减少依赖，以最大限度地提高可复用性。

==== _crew_ 目录

负责用户管理的应用模块，也是目前唯一包含 Taack 核心服务的必选基础应用。

=== _server_ 目录

存放全局配置、公共翻译、共享静态资源以及根页面的 Grails 应用。

*server* Grails 应用依赖于 _app_ 目录中定义的所有需要启用的应用模块（或 Grails 插件）。

=== _buildSrc_

公共 Gradle 配置。可以使用 Groovy 语言在此目录中定义额外的 Gradle 任务。

== _infra_ 仓库

存放 *taack-ui* 插件的源代码。

[plantuml, format="svg", opts="inline"]
----
@startsalt
{
{T
+ <&folder> infra     | Infra sources (see below)
++ <&folder> browser   | Browser code (Kotlin transpiled in Javascript)
++ <&folder> taack-jdbc-common| Common JDBC code
++ <&folder> taack-jdbc-client| Client JDBC code
++ <&folder> taack-ui | Taack User Interface code
++ <&folder> gradle           | Gradle binaries
++ <&file> build.gradle
++ <&file> settings.gradle
++ <&file> gradle.properties
++ <&file> gradlew

}
}
@endsalt
----

* _browser_ 文件夹包含将在浏览器中执行的代码
* _taack-jdbc-common_ 包含 _taack-ui_ 和 _taack-jdbc-client_ 之间共享的公共类
* _taack-jdbc-client_ 包含 JDBC 驱动程序（参见 link:../../more/JDBC/taack-jdbc-driver-zh.adoc[taack-jdbc-driver]）
