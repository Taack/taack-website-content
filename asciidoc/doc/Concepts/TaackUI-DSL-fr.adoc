== Avant-propos sur le Block DSL

Le Block DSL permet de spécifier la mise en page en définissant des blocs qui contiennent des éléments graphiques. Un bloc peut être mis à jour par des actions. Les `blocs AJAX` peuvent être ciblés à l'aide de leur ID. Les blocs peuvent également être imbriqués.

Pour plus d'informations, veuillez vous référer à la page dédiée au link:../DSLs/block-dsl.adoc[Block DSL]. Les PDF disposent de leur propre gestion de blocs via les link:../DSLs/block-printable-dsl-fr.adoc[Blocs imprimables], où les DSL d'affichage (show), de tableau (table) et de diagramme (diagram) sont également applicables.

[source,groovy]
----
UiBlockSpecifier b = new UiBlockSpecifier() <1>
b.ui {
    modal {                                 <2>
        form f                              <3>
    }
}
----

<1> Crée le bloc, construit via la méthode `ui`
<2> Ce bloc contiendra une fenêtre modale, qui est également un bloc
<3> La fenêtre modale contient un formulaire

== DSL d'éléments de bloc

* link:../DSLs/form-dsl-fr.adoc[*Form DSL*] : Permet de définir un formulaire à inclure dans un bloc

* link:../DSLs/show-dsl-fr.adoc[*Show DSL*] : Permet d'afficher le résumé d'un objet. Il prend en charge l'édition limitée de champs

* link:../DSLs/filter-table-dsl-fr.adoc[*DSL de tableau et de filtre de tableau*] : Un tableau est associé à zéro ou un filtre. Les filtres ne peuvent pas être affichés sans tableau.
** Le Table DSL permet de regrouper et de trier les colonnes
** La pagination est incluse
** Le tableau peut également représenter une arborescence
** Les lignes peuvent être modifiées directement en ligne (`rowQuickEdit`)
** Le filtre peut être affiché à côté du tableau ou sous forme de barre d'outils au-dessus de celui-ci (`FilterLayout`)
* link:../DSLs/diagram-dsl-fr.adoc[*Diagram DSL*] : Permet de dessiner des diagrammes (barres, lignes, aires, nuages de points, secteurs, boîtes à moustaches, chronologies) dans un bloc, un PDF ou un e-mail
* link:../DSLs/kanban-dsl-fr.adoc[*Kanban DSL*] : Permet de dessiner un tableau Kanban avec glisser-déposer entre les colonnes
* `custom` : Permet d'insérer du code HTML personnalisé dans un bloc.
