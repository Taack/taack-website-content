= Modulare Anwendungsentwicklung

Die https://github.com/Taack/intranet[Intranet-Beispielanwendung] ist eine modulare https://gradle.org/[Gradle]-Anwendung. Eine Anleitung zum Ausführen erhalten Sie unter: link:../../usage-de.adoc[Beispiel-Intranet installieren].

== Verzeichnisstruktur der Intranet-Beispielanwendung


[plantuml, format="svg", opts="inline", theme="spacelab"]
----
@startsalt
{
{T
+ <&folder> Intranet | Root Directory
++ <&folder> app    | Application Modules Directory
+++ <&folder> crew  | Mandatory base app to manage users
+++ <&folder> appModule1  | First application (Gradle module)
+++ <&folder> appModule2  | Second application
+++ <&folder> ...   | And so on
++ <&folder> buildSrc | Gradle Build Instructions
++ <&folder> server | Server Root Application (Grails app)
++ <&folder> gradle           | Gradle binaries
++ <&file> build.gradle
++ <&file> settings.gradle
++ <&file> gradle.properties
++ <&file> gradlew
}
}
@endsalt
----

=== Verzeichnis _app_

Enthält Grails-Plugins (oder Gradle-Module), aus denen sich die Intranet-Anwendung zusammensetzt. Diese Plugins sollten minimale Abhängigkeiten aufweisen, um die Wiederverwendbarkeit durch andere zu maximieren.

==== Verzeichnis _crew_

Teil der Anwendung, der für die Benutzerverwaltung zuständig ist; die einzige obligatorische Anwendung, die derzeit die Taack-Dienste enthält.

=== Verzeichnis _server_

Grails-Anwendung mit globaler Konfiguration, gemeinsamen Übersetzungen, statischen gemeinsam genutzten Ressourcen und der Startseite.

Die Grails-Anwendung *server* hängt von allen gewünschten Anwendungsmodulen (oder Grails-Plugins) ab, die im Verzeichnis _app_ definiert sind.

=== _buildSrc_

Gemeinsame Gradle-Konfiguration. Zusätzliche Gradle-Tasks können in diesem Verzeichnis in der Sprache Groovy definiert werden.

== Repository _infra_

Enthält den Quellcode des Plugins *taack-ui*.

[plantuml, format="svg", opts="inline"]
----
@startsalt
{
{T
+ <&folder> infra     | Infra sources (see below)
++ <&folder> browser   | Browser code (Kotlin transpiled in Javascript)
++ <&folder> taack-jdbc-common| Common JDBC code
++ <&folder> taack-jdbc-client| Client JDBC code
++ <&folder> taack-ui | Taack User Interface code
++ <&folder> gradle           | Gradle binaries
++ <&file> build.gradle
++ <&file> settings.gradle
++ <&file> gradle.properties
++ <&file> gradlew

}
}
@endsalt
----

* Der Ordner _browser_ enthält Code, der im Browser ausgeführt wird
* _taack-jdbc-common_ enthält gemeinsame Klassen, die von _taack-ui_ und _taack-jdbc-client_ genutzt werden
* _taack-jdbc-client_ ist der JDBC-Treiber (siehe link:../../more/JDBC/taack-jdbc-driver-de.adoc[taack-jdbc-driver])
