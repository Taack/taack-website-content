= Guide d'installation

== Prérequis

Pour commencer, assurez-vous que les outils suivants sont installés sur votre machine :

* *Java* (JDK 25 ...)
* *Git*
* https://github.com/unoconv/unoserver[unoserver]

=== Installer les prérequis

==== macOS (Homebrew)

.Installer JDK 24 et Git avec Homebrew
[source,bash]
----
$ brew install openjdk@25
$ brew install git
----

==== Windows (Winget)

.Installer JDK 25 et Git avec Winget
[source,bash]
----
winget install --id Microsoft.OpenJDK.25
winget install --id Git.Git
----

== Cloner l'intranet prêt pour le développement

.Clonez le dépôt de démarrage :

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
----

Ce dépôt inclut un squelette d'intranet minimal (gestion des utilisateurs Crew + *plugin Spring Security*) prêt pour le développement.


== Démarrer votre intranet

.Placez-vous dans le dossier de l'intranet nouvellement cloné et lancez le serveur :

[source,bash]
----
$ cd intranet
$ ./gradlew server:bootRun
----

[NOTE]
====
La commande `./gradlew` utilise le Gradle Wrapper, vous n'avez donc pas besoin d'installer Gradle manuellement.
====

.Une fois la compilation terminée, vous devriez voir :
[source,bash]
----
Grails application running at http://localhost:9442
----

Pour modifier le mot de passe administrateur par défaut, éditez les fichiers suivants :

* `server/grails-app/conf/application.yml`
* `server/grails-app/conf/application-MACOSX.yml`

Recherchez la ligne :
[source,yaml]
taack.admin.password: ChangeIt

Après avoir effectué la modification, supprimez le fichier `intranetDb.mv.db` pour appliquer le nouveau mot de passe.


[NOTE]
====
`application-MACOSX.yml` n'est utilisé que lorsque l'application détecte un environnement macOS. Si vous utilisez Linux ou Windows, il sera ignoré.
====

[WARNING]
====
La suppression du fichier `intranetDb.mv.db` effacera définitivement toutes les données précédemment enregistrées.
====




=== Configurer une base de données persistante

Si vous souhaitez que les données soient persistantes, modifiez les fichiers `server/grails-app/conf/application.yml` et
`server/grails-app/conf/application-MACOSX.yml` pour utiliser une base de données persistante.

.Ici, nous souhaitons que H2 persiste les données dans un fichier en mode développement :

[source,yaml]
----
environments:
    development:
        dataSource:
            dbCreate: update        <1>
            url: jdbc:h2:./intranetDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE <2>
----

<1> Mode de création (voir la documentation Grails GORM)
<2> `intranetDb` : racine du nom de fichier contenant les données

=== Produire un fichier JAR pour Tomcat

.Utilisez la tâche assemble au lieu de bootRun :

[source,bash]
----
$ ./gradlew server:assemble
----
Le JAR assemblé (par ex. `server-0.6.jar`) se trouvera dans `server/build/libs`.


.Vous pouvez le déployer sur votre serveur de production ou le tester localement

[source,bash]
----
cd server/build/libs
java -jar server-[version].jar   <1>
----
<1> Le numéro de version se trouve dans `build.gradle`. La valeur par défaut est 0.6

[TIP]
====
Assurez-vous que l'application n'est pas déjà en cours d'exécution lorsque vous démarrez une nouvelle instance.
====


== Configurer votre IDE


Nous recommandons vivement d'utiliser la dernière version d'*IntelliJ Ultimate Edition* pour sa prise en charge complète de *Groovy* et *Grails*.

=== IntelliJ Ultimate Edition

Nous recommandons d'installer le *plugin IntelliJ Taack*, que vous pouvez installer depuis l'IntelliJ Marketplace https://plugins.jetbrains.com/plugin/20792-taackuiastautocomplete[TaackUiASTAutocomplete] ou directement depuis le https://github.com/Taack/infra/releases/tag/v0.1[dépôt de code source].

Ouvrez le projet, allez dans File > Open... et sélectionnez `intranet/settings.gradle`.

Assurez-vous que Gradle utilise le JDK 25 :

.Ouvrir les paramètres Gradle et vérifier la version du JDK Gradle
image:install-java25-gradle-select.webp[]

<1> Ouvrir les paramètres Gradle
<2> Vérifier que la version de la JVM Gradle est 25 (le fournisseur peut être quelconque)

=== Visual Studio Code

Si vous préférez Visual Studio Code, nous recommandons les extensions suivantes pour utiliser ce framework :

* https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack[Extension Pack for Java]
* https://marketplace.visualstudio.com/items?itemName=marlon407.code-groovy[code-groovy]
* https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-gradle[Gradle for Java]
* https://marketplace.visualstudio.com/items?itemName=MellowMarshmallow.groovy[Groovy]

[NOTE]
====
La plupart des fonctionnalités de Grails et du framework Taack ne seront pas reconnues par VS Code. Les imports, la navigation et l'assistance au code peuvent être limités. IntelliJ reste l'IDE privilégié pour une prise en charge complète.
====
