[[filterFieldExpressionReverse]]
.Nuevo filtro filterFieldExpressionReverse
====
.Filtro filterFieldExpressionReverse
[source,groovy]
----
def parentParts() {
    UiFilterSpecifier f = new UiFilterSpecifier().sec PlmFreeCadPart, {         <1>
        PlmFreeCadLink link = new PlmFreeCadLink()
        filterFieldExpressionReverse(link.part_,                                <2>
                true,                                                           <3>
                new FilterExpression(null as Object, Operator.NE, link.part_))  <4>
    }
    taackUiService.show(new UiBlockSpecifier().ui {
        tableFilter(plmFreeCadUiService.buildPartFilter(), plmFreeCadUiService.buildPartTable(null, f), {
            menuIcon ActionIcon.GRAPH, this.&model as MC
        })
    }, buildMenu())
}
----
<1> Estamos construyendo un filtro para `PlmFreeCadPart`
<2> Queremos listar los ensamblajes padre, aquellos para los cuales el campo `PlmFreeCadLink part` no apunta al `PlmFreeCadPart` listado
<3> `true` significa `notIn`
<4> Literalmente: queremos todos los *PlmFreeCadPart* que no sean hijos

.HQL generado
[source,hql]
----
select
    distinct sc  ,sc.dateCreated
from PlmFreeCadPart sc
where
    sc.id NOT IN (select auo.part.id from PlmFreeCadLink auo where auo.part IS NOT NULL)    <1>
    and sc.nextVersion IS NULL
order by sc.dateCreated DESC
----

<1> Cláusula `where` añadida por la expresión `filterFieldExpressionReverse`

[[show-grid-layout]]
.Diseño de cuadrícula para Show (Show Grid Layout)
====

.Distribuir un Show en una cuadrícula adaptable mediante `ShowLayout.GRID`
[source,groovy]
----
new UiShowSpecifier().ui ShowLayout.GRID, {                      <1>
    fieldLabeled item.ref_
    fieldLabeled item.name_
    fieldLabeled item.itemStatus_
    fieldLabeled item.gtin_
    fieldLabeled Style.SPAN_TWO, item.labeling_                  <2>
    fieldLabeled Style.BOLD + Style.SPAN_FULL, item.description_ <3>
}
----

<1> Pase `ShowLayout.GRID` para distribuir los campos en una cuadrícula autoajustable en lugar de verticalmente en una columna. El valor predeterminado es `ShowLayout.LIST`.
<2> Cada campo ocupa una celda de la cuadrícula de forma predeterminada. `Style.SPAN_TWO` / `Style.SPAN_THREE` se pueden usar para permitir que las celdas abarquen más columnas.
<3> `Style.SPAN_FULL` hace que un campo abarque toda la fila. Las expansiones se combinan con cualquier otro estilo mediante `+` (aquí con `Style.BOLD`).

Tenga en cuenta que la cuadrícula ajusta automáticamente tantas columnas como permita el ancho del contenedor, cada una de al menos `220px` de ancho (`grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))` en la clase `taackShowGrid`; el mínimo se puede sobrescribir en su CSS).

== Versión 0.7.0

* Grails 7, Gradle 8.4, Java 24, Groovy 4.0.28 ...
* Mejora del rendimiento: comienza a transmitir la página antes y consume menos memoria por página
* División de `taack-ui` en `taack-ui`, `taack-ui-jdbc`, `taack-ui-pdf`, `taack-ui-ssh`, `taack-ui-search`, `taack-ui-asciidoc`. Un servidor mínimo que use solo `taack-ui` debería ser un Jar de unos 70 MB de tamaño
* Menús contextuales para campos y clases (consulte <<contextual-menu-code-sample>>)
* Asistente de notificaciones: permite marcar filas no leídas en una tabla mediante el setter de filtro `setLastReadingDate` (consulte <<notification-setLastReadingDate-sample>>)
* #Cambios en SolrSearch#: el contexto de los objetos debe registrarse de manera genérica (consulte <<TaackGormClassRegisterService>>)
* Nueva personalización de diagramas mediante builders, facilitando la integración de diagramas en correos y PDF (consulte <<diagram-builders>>)
* Editor Asciidoc con capacidades de conversión al copiar y pegar (consulte <<asciidoc-editor>>)
* Mejora de las salidas de diagramas en correos y PDF
* `TaackUiConfiguration` no se inicializa mediante `application.yml`; sus miembros son estáticos y se pueden modificar en `server/grails-app/init/.../Application.groovy` (consulte <<taack-ui-configuration>>)
* Ahora es posible recibir una llamada de retorno (callback) en un evento de soltar (drop) sobre una tabla o una celda de tabla (consulte <<drop-on-table>>, <<drop-on-cell>>)
