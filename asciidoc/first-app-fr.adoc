= Première application

== Comment fonctionne l'application avec le framework Taack ?

Votre projet d'intranet comporte deux parties :

* Les plugins d'application, situés dans le dossier `app`, sont des micro-projets, chacun ayant ses propres dépendances, sa propre compilation, etc. (par ex., Crew).
Pour une explication plus détaillée de la déclaration des plugins, consultez link:doc/plugin/taack-plugin.adoc#_about_plugins[À propos des plugins].
* Le serveur principal utilise tous les plugins d'application déclarés dans son fichier `build.gradle` et les affiche sur la page principale de l'intranet.

== Créer un nouveau plugin d'application


Pour créer un nouveau plugin d'application (un module Gradle), assurez-vous d'avoir récupéré la dernière version de votre intranet depuis notre dépôt GitHub (voir link:install.adoc[installation]).

.Exécutez la commande suivante depuis le dossier racine de votre intranet :

// setting system properties with the -D flag
// setting project properties with the -P flag

[,bash]
----
$ ./gradlew -DmodName=myBooks server:generateTaackAppTask
----

Cela crée un nouveau dossier `app/myBooks`.

[NOTE]
====
Sous `intranet/app/myBooks/grails-app/domain`, remplacez le répertoire `myBooks` par `my.books`, ce qui garantira l'accès aux classes créées dans `domain` depuis `controllers` et `services`, car elles feront partie du même package.
====

== Gérer les futures mises à jour

La plupart du temps, la mise à jour de votre intranet implique de mettre à jour le dossier `buildSrc`, le fichier `gradle.properties` et, plus rarement, les fichiers `build.gradle` des applications.

[NOTE]
====
En réalité, ce processus est courant dans le développement logiciel à long terme et ne devrait pas intimider les nouveaux venus.
====

== Créer un tableau

Affichons maintenant un tableau dans notre page `listBook`. Allez dans `grails-app/services/my/books/MyBooksUiService`.

.Créez un nouveau spécificateur de tableau appelé `buildBookTable` :
[,groovy]
----

UiTableSpecifier buildBookTable() {
    Book book = new Book()
    UiTableSpecifier bookTableSpecifier = new UiTableSpecifier()
    bookTableSpecifier.ui {
    //Add table content inside the closure here
    }
}

----
Ici, nous définissons un nouveau tableau qui listera les instances de `Book`. Utilisez `import taack.ui.dsl.UiTableSpecifier`.





.Pour définir les en-têtes du tableau, ajoutez le code suivant dans la closure (importez les classes nécessaires) :
[,groovy]
----
bookTableSpecifier.ui {
    // -- Header --
    header {
        column {
            sortableFieldHeader book.title_ //<1>
        }
        column {
            label book.authorName_
        }
        column {
            label book.numberOfPages_
        }
        column {
            label "Delete book"
        }
    }
}
----
<1> Notez qu'ici nous utilisons `sortableFieldHeader`, ce qui rend la colonne triable : vous pouvez trier les livres par ordre alphabétique en cliquant sur l'en-tête `book.title`.
Maintenant, nous allons remplir notre tableau : nous allons parcourir les instances de `Book` dans la base de données à l'aide de la méthode DSL de tableau `iterate`.

.Ajoutez le code suivant (initialisez et importez les classes nécessaires) :
[,groovy]
----
bookTableSpecifier.ui {
    //table headers...

    iterate(taackFilterService.getBuilder(Book) // <1>
        .setMaxNumberOfLine(8) // <2>
        .setSortOrder(TaackFilter.Order.DESC, book.title_) // <3>
        .build()) { Book bookIterator ->
    rowColumn {
        rowField bookIterator.title_ // <4>
    }
    rowColumn {
        rowField bookIterator.authorName_
    }
    rowColumn {
        rowField bookIterator.numberOfPages_
    }
    rowColumn {
        rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN, // <5>
            MyBooksController.&deleteBook as MethodClosure, bookIterator.id
        }
    }
}

----
<1> Utilisez `import taack.domain.TaackFilterService`.
<2> Seuls les huit premiers livres seront affichés.
<3> Définit l'ordre d'affichage selon le titre des livres par ordre décroissant (utilisez `import taack.domain.TaackFilter`).
<4> Le tiret bas (underscore) est nécessaire ici.
<5> Utilisez `import taack.ui.dsl.common.ActionIcon
import taack.ui.dsl.common.IconStyle`.

[NOTE]
====
Nous devons créer l'action `deleteBook`. Pour l'instant, nous la laisserons vide.
====

Allez dans `grails-app/controllers/my/books/MyBooksController.groovy`.

.Ajoutez la méthode suivante après l'action `index` :
[,groovy]
----
def deleteBook () {}
----

Pour chaque livre de notre liste, nous créons une nouvelle ligne avec le titre du livre dans la première colonne, suivi de l'auteur, du nombre de pages et d'un bouton btn:[Delete] dans la quatrième colonne.

Votre tableau est maintenant complet ; il ne nous reste plus qu'à l'afficher sur la page.
Pour afficher les `UiSpecifier` précédemment construits, nous devons utiliser `taackUiService`, qui devrait déjà être importé dans le contrôleur créé par la commande `create-taack-app`.


Nous ferons cela dans une action appelée `listBook` : dans la méthode `index`, remplacez son contenu par une redirection vers l'action `listBook`.

.Rediriger vers l'action `listBook` :
[,groovy]
----

}
----

        taackUiService.show(new UiBlockSpecifier().ui {

<1> Récupère le `tableSpecifier` que nous avons créé depuis `MyBooksUiService`.

Utilisez `import taack.ui.dsl.UiTableSpecifier`.

`taackUiService.show(UiBlockSpecifier block, UiMenuSpecifier menu)` se chargera du rendu de la spécification que nous lui passons.
Nous utilisons la méthode statique `buildMenu()` créée précédemment dans `MyBooksUiService` comme second argument de `show()` pour afficher le menu avec la page.

== Créer un formulaire et enregistrer des objets

Nous allons maintenant créer le formulaire qui servira à créer et mettre à jour des livres.
Pour gérer les deux cas, nous allons initialiser un nouveau `Book` ou lire le livre si un identifiant de `Book` a été passé dans les paramètres de la requête dans `MyBooksUiService`.

.Créez un nouveau spécificateur de formulaire appelé `buildBookForm` :
[,groovy]
----
UiFormSpecifier buildBookForm(Book book) {
    book ?= new Book(params) // <1>
}
----
<1> Cela signifie que si `book` est null, on lui assigne une nouvelle instance à l'aide des paramètres de la requête.

Définissons maintenant son formulaire et son contenu.

.Ajoutez ce qui suit dans `buildBookForm` (importez les classes nécessaires) :
[,groovy]
----
UiFormSpecifier bookFormSpecifier = new UiFormSpecifier()
bookFormSpecifier.ui book, {
    //Section of fields
    section "Book details", {
        field book.title_
        field book.authorName_
        field book.numberOfPages_
    }
    //Save button
    formAction MyBooksController.&saveBook as MethodClosure // <1>
}
----
<1> Vous devrez définir l'action `saveBook` (comme pour `deleteBook`) dans `MyBooksController`.

Utilisez `import taack.ui.dsl.UiFormSpecifier`.

Une fois votre formulaire défini, vous pouvez l'afficher à l'aide de la méthode `taackUiService.show()`.

.Ajoutez ce qui suit dans la méthode `bookForm` de `MyBooksController` :
[,groovy]
----
def bookForm(Book book) {
    UiFormSpecifier tableFormSpecifier = myBooksUiService.buildBookForm book

    taackUiService.show new UiBlockSpecifier().ui {
        modal {
            form tableFormSpecifier
        }
    }
}
----

Utilisez `import taack.ui.dsl.UiFormSpecifier`.

Cette fois, nous ne spécifions pas `buildMenu` dans notre appel à `show`, car nous ne voulons pas que le menu soit affiché à l'intérieur de la fenêtre modale.

.Modifiez l'action `saveBook` (importez et initialisez les classes nécessaires) :

[,groovy]
----
@Transactional
def saveBook() {
    taackSaveService.saveThenReloadOrRenderErrors(Book)
}
----
Utilisez `import taack.render.TaackSaveService` et `import grails.gorm.transactions.Transactional`.

[NOTE]
====
Consultez link:doc/DSLs/block-dsl.adoc#_modal_stack_code_sample[Fermer la modale et recharger la page] pour savoir comment éviter l'utilisation de `redirectAction` lors de la sauvegarde...
====

== Afficher un objet

Maintenant que nous pouvons créer des livres et en voir la liste dans un tableau, affichons chaque livre plus en détail à l'aide d'une fenêtre modale.
Une fois encore, nous définissons le spécificateur et nous l'affichons dans un bloc modal avec `taackUiService.show()`.


.Créez `showBook` (importez la classe nécessaire) :
[,groovy]
----
def showBook(Book book) {
    // Define the show displayed fields
    UiShowSpecifier showSpec = new UiShowSpecifier().ui({
        fieldLabeled book.title_
        fieldLabeled book.authorName_
    })

    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            show showSpec
        }
    })
}
----
Utilisez `import taack.ui.dsl.UiShowSpecifier`.

Nous devons également afficher un lien vers cette fenêtre modale dans le tableau. Pour cela, ajoutez la ligne suivante dans la même `rowColumn` (sous le champ du titre du livre) où vous souhaitez voir apparaître le bouton dans `MyBooksUiService` :

.Ajoutez 2 lignes dans `buildBookTable` :
[,groovy]
----

UiTableSpecifier buildBookTable() {
    //Section of code
    rowColumn {
        //Add these 2 lines
        rowAction ActionIcon.SHOW * IconStyle.SCALE_DOWN, // <1>
        MyBooksController.&showBook as MethodClosure, bookIterator.id
        rowField bookIterator.title_
    }
    //Section of code
}


----

<1> Ici, nous réduisons la taille de l'icône avec l'opérateur de multiplication.

Cela créera un _petit_ bouton icône dans la cellule du tableau qui ouvrira une fenêtre modale contenant les informations du livre correspondant.

Notez que `ActionIcon` a été multiplié par un `IconStyle` pour modifier sa taille dans ce cas.

== Filtrage
Si nous ajoutons trop de livres, nous risquons de perdre du temps à chercher un livre précis ; filtrer les livres permet de rendre la recherche plus efficace. Implémentons cela dans `MyBooksUiService`.


.Créez un nouveau spécificateur de filtre appelé `buildBookFilter` :
[,groovy]
----
UiFilterSpecifier buildBookFilter(Book book) {
    UiFilterSpecifier bookFilterSpecifier = new UiFilterSpecifier() // <1>

    bookFilterSpecifier.ui Book, { // <2>
        section "Book Filter", {  // <3>
            filterField book.title_ // <4>
        }
    }
}
----
<1> Créez le filtre. Utilisez `import taack.ui.dsl.UiFilterSpecifier`.
<2> Passez la classe de l'objet et la closure contenant les spécifications du filtre via la méthode `ui`.
<3> Créez une section intitulée "Book Filter".
<4> Ajoutez un champ au filtre, notez le *tiret bas* à la fin du nom du champ.

L'étape suivante consiste à afficher ce filtre nouvellement créé.

.Modifiez `taackUiService.show` dans `listBook` (situé dans `MyBooksController`) :
[,groovy]
----
def listBook() {
    Book book = new Book()
    UiTableSpecifier tableBookSpecifier = myBooksUiService.buildBookTable()
    UiFilterSpecifier filterBookSpecifier = myBooksUiService.buildBookFilter book

    taackUiService.show(new UiBlockSpecifier().ui {
        tableFilter filterBookSpecifier, tableBookSpecifier, {
            menuIcon ActionIcon.CREATE, this.&bookForm as MethodClosure
        }
    }, MyBooksUiService.buildMenu())
}
----
Utilisez `import taack.ui.dsl.UiFilterSpecifier`.

== Ajouter un second menu
Vous vous souvenez de la classe `Author` que nous avons créée au début ? Il est temps de l'utiliser ! Nous allons créer un second menu dans lequel nous pourrons ajouter des auteurs et les filtrer.

.Ajoutez cette ligne de code dans `buildMenu` dans `MyBooksUiService` :
[,groovy]
----
menu MyBooksController.&listAuthor as MC
----
Cela crée un second menu dans le coin supérieur gauche pour accéder à la page des auteurs.

[NOTE]
====
Vous pouvez également créer des sous-menus imbriqués dans le menu principal.
[,groovy]
----
label("Menu", {
    subMenu(MyBooksController.&index as MC)
    subMenu(MyBooksController.&listAuthor as MC)
})
----
Cela crée un sous-menu intitulé "Menu" contenant un lien vers l'action `index` (qui correspond à l'action `listBook`) et vers l'action `listAuthor`. C'est utile si vous souhaitez regrouper des liens associés sous un même élément de menu.
====
.Ajoutez les constructeurs suivants dans `MyBooksUiService` :
[,groovy]
----
UiTableSpecifier buildAuthorTable(Boolean isSelect = false ) {
    Author author = new Author()
    UiTableSpecifier authorTableSpecifier = new UiTableSpecifier()
    authorTableSpecifier.ui {
        header {
            column {
                sortableFieldHeader author.firstName_
            }
            column {
                sortableFieldHeader author.lastName_
            }
            column {
                label author.dateOfBirth_
            }
            column {
                label "Delete Author"
            }
        }

        iterate(taackFilterService.getBuilder(Author)
                .setMaxNumberOfLine(8)
                .setSortOrder(TaackFilter.Order.DESC, author.lastName_)
                .build()) { Author authorIterator ->
            rowColumn {
                rowField authorIterator.firstName_
                rowAction ActionIcon.SHOW * IconStyle.SCALE_DOWN,
                        MyBooksController.&showAuthor as MethodClosure, authorIterator.id
            }
            rowColumn {
                rowField authorIterator.lastName_
            }
            rowColumn {
                rowField authorIterator.dateOfBirth_
            }
            rowColumn {
                rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN,
                        MyBooksController.&deleteAuthor as MC, authorIterator.id
            }
        }
    }
}

UiFormSpecifier buildAuthorForm(Author author) {
    author ?= new Author(params)
    UiFormSpecifier authorFormSpecifier = new UiFormSpecifier()
    authorFormSpecifier.ui author, {
        section "Author details", {
            field author.firstName_
            field author.lastName_
            field author.dateOfBirth_
        }
        formAction MyBooksController.&saveAuthor as MC
    }
}

UiFilterSpecifier buildAuthorFilter() {
    Author author = new Author()

    authorFilterSpecifier.ui Author, {
        section "Author Filter", {

== Dépannage et erreurs courantes

.Sortie d'erreur :
[source,console]
----
ERROR: Cannot resolve symbol 'MyBooksUiService'
----
Vous avez oublié de recharger Gradle après avoir créé le plugin. Cliquez sur le bouton de rechargement de Gradle dans votre IDE.

.Sortie d'erreur :
[,console]
----
ERROR:  Field 'authorName_' not found
----
Vous avez renommé le champ `authorName` en `author` (une référence à `Author`). Assurez-vous d'avoir remplacé tous les `authorName_` par `author_` à la fois dans le formulaire et dans le tableau.

.Sortie d'erreur :
[,console]
----
ERROR: No matching method for action...
----
Assurez-vous d'avoir déclaré la méthode correspondante dans `MyBooksController` et d'avoir utilisé correctement la syntaxe `MethodClosure` : `MyBooksController.&myMethod as MethodClosure`.


.Le formulaire s'affiche mais n'enregistre pas :
Il vous manque peut-être l'annotation `@Transactional` sur la méthode `saveBook` ou vous avez oublié d'importer `taackSaveService`.

.Erreur de base de données après le renommage de champs :
Si vous avez modifié des champs dans des classes du domaine, vous devez supprimer les fichiers de base de données :
`intranet/server/intranetDb.mv.db`
`intranet/server/intranetDb.trace.db`. Attention, cela effacera toutes les données enregistrées précédemment.

.Le connecteur de base de données ne valide pas la transaction (flush) :

Vous utilisez peut-être la mauvaise annotation `@Transactional`. Veillez à utiliser celle du package GORM et non celle de Javax.

.Accéder à la console de base de données H2 :

Vous souhaiterez peut-être vérifier l'intégrité des données et les DDL générés par la base de données embarquée H2.

Pour ce faire, vous devez ajuster les paramètres de Spring Security.

Naviguez vers
Root → /server → /grails-app → /conf

Vous y trouverez un fichier `application.groovy`.

Ajoutez

```groovy
[pattern: '/h2-console/**',  access: ['permitAll']],
```
à ce bloc de configuration :
```groovy
grails.plugin.springsecurity.controllerAnnotations.staticRules = [
	[pattern: '/',               access: ['permitAll']],
	[pattern: '/error',          access: ['permitAll']],
	[pattern: '/index',          access: ['permitAll']],
	[pattern: '/index.gsp',      access: ['permitAll']],
	[pattern: '/shutdown',       access: ['permitAll']],
	[pattern: '/assets/**',      access: ['permitAll']],
	[pattern: '/**/js/**',       access: ['permitAll']],
	[pattern: '/**/css/**',      access: ['permitAll']],
	[pattern: '/**/images/**',   access: ['permitAll']],
	[pattern: '/**/favicon.ico', access: ['permitAll']]
]
```
