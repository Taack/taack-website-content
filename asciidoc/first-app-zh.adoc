= 第一个应用

== 应用如何与 Taack 框架配合工作？

您的内网项目包含两个部分：

* 位于 `app` 目录下的应用插件是独立的微项目，每个微项目都有自己的依赖和构建配置等（例如 Crew）。
有关如何声明插件的更详细说明，请参阅 link:doc/plugin/taack-plugin.adoc#_about_plugins[关于插件]。
* 主服务器会引入其 `build.gradle` 中声明的所有应用插件，并将它们显示在内网主页上。

== 创建新的应用插件


若要创建新的应用插件（即一个 Gradle 模块），请确保您已从我们的 GitHub 仓库拉取了最新版本的内网代码（请参阅 link:install.adoc[安装指南]）。

.在内网根目录下执行以下命令：

// setting system properties with the -D flag
// setting project properties with the -P flag

[,bash]
----
$ ./gradlew -DmodName=myBooks server:generateTaackAppTask
----

这将创建一个新目录 `app/myBooks`。

[NOTE]

== 创建表格

现在让我们在 `listBook` 页面中显示一个表格。请打开 `grails-app/services/my/books/MyBooksUiService`。

.创建一个名为 `buildBookTable` 的表格描述器（Specifier）：
[,groovy]
----

UiTableSpecifier buildBookTable() {
    Book book = new Book()
    UiTableSpecifier bookTableSpecifier = new UiTableSpecifier()
    bookTableSpecifier.ui {
    //Add table content inside the closure here
    }
}

----
这里我们定义了一个用于列出 `Book` 实例的新表格。请使用 `import taack.ui.dsl.UiTableSpecifier`。





.若要定义表头，请在闭包中添加以下代码（并导入所需的类）：
[,groovy]
----
bookTableSpecifier.ui {
    // -- Header --
    header {
        column {
            sortableFieldHeader book.title_ //<1>
        }
        column {
            label book.authorName_
        }
        column {
            label book.numberOfPages_
        }
        column {
            label "Delete book"
        }
    }
}
----
<1> 注意这里我们使用了 `sortableFieldHeader`，这会使该列支持排序，您可以通过点击 `book.title` 表头按字母顺序对书籍进行排序。
接下来我们将填充表格，使用表格 DSL 的 `iterate` 方法遍历数据库中的 `Book` 实例。

.添加以下代码（初始化并导入所需的类）：
[,groovy]
----
bookTableSpecifier.ui {
    //table headers...

    iterate(taackFilterService.getBuilder(Book) // <1>
        .setMaxNumberOfLine(8) // <2>
        .setSortOrder(TaackFilter.Order.DESC, book.title_) // <3>
        .build()) { Book bookIterator ->
    rowColumn {
        rowField bookIterator.title_ // <4>
    }
    rowColumn {
        rowField bookIterator.authorName_
    }
    rowColumn {
        rowField bookIterator.numberOfPages_
    }
    rowColumn {
        rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN, // <5>
            MyBooksController.&deleteBook as MethodClosure, bookIterator.id
        }
    }
}

----
<1> 请使用 `import taack.domain.TaackFilterService`。
<2> 每页仅显示前 8 本书。
<3> 设置按书名降序排列显示（请使用 `import taack.domain.TaackFilter`）。
<4> 此处末尾的下划线是必需的。
<5> 请使用 `import taack.ui.dsl.common.ActionIcon
import taack.ui.dsl.common.IconStyle`。

== 创建表单并保存对象

现在我们来构建用于创建和更新书籍的表单。
为了同时处理这两种情况，我们将在 `MyBooksUiService` 中判断请求参数是否传入了书籍 ID：若有则读取该书籍，否则初始化一个新的 `Book` 实例。

.创建一个名为 `buildBookForm` 的表单描述器：
[,groovy]
----
UiFormSpecifier buildBookForm(Book book) {
    book ?= new Book(params) // <1>
}
----
<1> 这表示如果 `book` 为 null，则使用请求参数为其赋一个新的实例。

接下来我们定义表单及其内容。

.在 `buildBookForm` 中添加以下代码（并导入所需的类）：
[,groovy]
----
UiFormSpecifier bookFormSpecifier = new UiFormSpecifier()
bookFormSpecifier.ui book, {
    //Section of fields
    section "Book details", {
        field book.title_
        field book.authorName_
        field book.numberOfPages_
    }
    //Save button
    formAction MyBooksController.&saveBook as MethodClosure // <1>
}
----
<1> 您需要在 `MyBooksController` 中定义 `saveBook` 操作（与 `deleteBook` 类似）。

请使用 `import taack.ui.dsl.UiFormSpecifier`。

定义好表单后，您可以使用 `taackUiService.show()` 方法将其显示出来。

.在 `MyBooksController` 的 `bookForm` 方法中添加以下代码：
[,groovy]
----
def bookForm(Book book) {
    UiFormSpecifier tableFormSpecifier = myBooksUiService.buildBookForm book

    taackUiService.show new UiBlockSpecifier().ui {
        modal {
            form tableFormSpecifier
        }
    }
}
----

请使用 `import taack.ui.dsl.UiFormSpecifier`。

这次我们在调用 `show` 时没有传入 `buildMenu`，因为我们不希望在模态窗口内部渲染菜单。

.修改 `saveBook` 操作（导入并初始化所需的类）：

[,groovy]
----
@Transactional
def saveBook() {
    taackSaveService.saveThenReloadOrRenderErrors(Book)
}
----
请使用 `import taack.render.TaackSaveService` 和 `import grails.gorm.transactions.Transactional`。

请参阅 link:doc/DSLs/block-dsl.adoc#_modal_stack_code_sample[关闭模态窗口并重新加载页面]，了解如何在保存时避免使用 `redirectAction`...

def showBook(Book book) {

        fieldLabeled book.authorName_

            show showSpec
        }
    })
}
----

.在 `MyBooksUiService` 中添加以下构建方法：
[,groovy]
----
UiTableSpecifier buildAuthorTable(Boolean isSelect = false ) {
    Author author = new Author()
    UiTableSpecifier authorTableSpecifier = new UiTableSpecifier()
    authorTableSpecifier.ui {
        header {
            column {
                sortableFieldHeader author.firstName_
            }
            column {
                sortableFieldHeader author.lastName_
            }
            column {
                label author.dateOfBirth_
            }
            column {
                label "Delete Author"
            }
        }

        iterate(taackFilterService.getBuilder(Author)
                .setMaxNumberOfLine(8)
                .setSortOrder(TaackFilter.Order.DESC, author.lastName_)
                .build()) { Author authorIterator ->
            rowColumn {
                rowField authorIterator.firstName_
                rowAction ActionIcon.SHOW * IconStyle.SCALE_DOWN,
                        MyBooksController.&showAuthor as MethodClosure, authorIterator.id
            }
            rowColumn {
                rowField authorIterator.lastName_
            }
            rowColumn {
                rowField authorIterator.dateOfBirth_
            }
            rowColumn {
                rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN,
                        MyBooksController.&deleteAuthor as MC, authorIterator.id
            }
        }
    }
}

UiFormSpecifier buildAuthorForm(Author author) {
    author ?= new Author(params)
    UiFormSpecifier authorFormSpecifier = new UiFormSpecifier()
    authorFormSpecifier.ui author, {
        section "Author details", {
            field author.firstName_
            field author.lastName_
            field author.dateOfBirth_
        }
        formAction MyBooksController.&saveAuthor as MC
    }
}

UiFilterSpecifier buildAuthorFilter() {
    Author author = new Author()
    UiFilterSpecifier authorFilterSpecifier = new UiFilterSpecifier()

    authorFilterSpecifier.ui Author, {
        section "Author Filter", {
            filterField author.lastName_
        }
    }
}

== 将作者关联到书籍

.在 `Author` 类中添加以下方法：
[,groovy]
----
String toString() {
    return firstName + ' ' + lastName
}
----

.修改 `Book` 类中的成员变量：
[,groovy]
----
Author author
----

[NOTE]
====
请将 `MyBooksController` 和 `MyBooksUiService` 中所有的 `book.authorName_` 替换为 `book.author_`，并将所有的 `bookIterator.authorName_` 替换为 `bookIterator.author_`。
====


[WARNING]
====
强烈建议不要随意修改类的名称或字段，因为这需要清除包含先前已添加数据的数据库文件。
您必须删除 `intranet/server/intranetDb.mv.db` 和 `intranet/server/intranetDb.trace.db` 以避免数据完整性错误。这将删除之前保存的所有数据。
====

.在 `messages.properties` 中添加一行：
[,properties]
----
default.author.label=Author Name
----

.修改位于 `MyBooksUiService` 中的 `buildAuthorTable`：
[,groovy]
----
rowColumn {
    rowField authorIterator.firstName_
    rowAction ActionIcon.SHOW * IconStyle.SCALE_DOWN,
            MyBooksController.&showAuthor as MethodClosure, authorIterator.id
    // Add the following if statement
    if (isSelect)
        rowAction tr('default.role.label'), ActionIcon.SELECT * IconStyle.SCALE_DOWN, authorIterator.id, authorIterator.toString()
}
----
这将添加一个选择按钮，以便在填写 `bookForm` 时选择作者。请使用 `import static taack.render.TaackUiService.tr`。

.修改位于 `MyBooksUiService` 中的 `buildBookForm`，替换 `field book.author_`：
[,groovy]
----
ajaxField book.author_, MyBooksController.&selectAuthor as MC
----
当在 `bookForm` 中选择作者时，该行代码会调用 `selectAuthor`。

接下来让我们实现 `selectAuthor`。

.在 `MyBooksController` 中实现 `selectAuthor`：
[,groovy]
----
def selectAuthor() {
    UiTableSpecifier t = myBooksUiService.buildAuthorTable true // <1>
    UiFilterSpecifier f = myBooksUiService.buildAuthorFilter()
    taackUiService.show new UiBlockSpecifier().ui {
        modal {
            tableFilter f, t
        }
    }
}
----
<1> 注意此处 `isSelect` 为 `true`。
当为书籍表单选择作者时，这会渲染一个紧凑版的 `Author` 表格及其过滤器。

== 故障排除与常见错误

.错误输出：
[source,console]
----
ERROR: Cannot resolve symbol 'MyBooksUiService'
----
您在创建插件后忘记重新加载 Gradle 了。请点击 IDE 中的 Gradle 重新加载按钮。

.错误输出：
[,console]
----
ERROR:  Field 'authorName_' not found
----
您将 `authorName` 字段重命名为了 `author`（指向 `Author` 的引用）。请确保已在表单和表格中将所有的 `authorName_` 替换为 `author_`。

.错误输出：
[,console]
----
ERROR: No matching method for action...
----
请确保已在 `MyBooksController` 中声明了对应的方法，并且正确使用了 `MethodClosure` 语法：`MyBooksController.&myMethod as MethodClosure`。


.表单可以显示但无法保存：
您可能遗漏了 `saveBook` 方法上的 `@Transactional` 注解，或者忘记导入 `taackSaveService`。

.重命名字段后出现数据库错误：
如果您修改了领域类中的字段，则必须删除数据库文件：
`intranet/server/intranetDb.mv.db`
`intranet/server/intranetDb.trace.db`。请注意，这会清除之前保存的所有数据。

.数据库连接器未刷新事务（Flush）：

您可能使用了错误的 `@Transactional` 注解。请注意应当使用来自 GORM 包的注解，而不是 Javax 包中的注解。

.访问 H2 数据库控制台：

您可能希望检查内嵌 H2 数据库的数据完整性和生成的 DDL。

为此，您需要调整 Spring Security 的配置。

请前往
Root → /server → /grails-app → /conf

您会找到一个 `application.groovy` 文件。

将

```groovy
[pattern: '/h2-console/**',  access: ['permitAll']],
```
添加到以下配置块中：
```groovy
grails.plugin.springsecurity.controllerAnnotations.staticRules = [
	[pattern: '/',               access: ['permitAll']],
	[pattern: '/error',          access: ['permitAll']],
	[pattern: '/index',          access: ['permitAll']],
	[pattern: '/index.gsp',      access: ['permitAll']],
	[pattern: '/shutdown',       access: ['permitAll']],
	[pattern: '/assets/**',      access: ['permitAll']],
	[pattern: '/**/js/**',       access: ['permitAll']],
	[pattern: '/**/css/**',      access: ['permitAll']],
	[pattern: '/**/images/**',   access: ['permitAll']],
	[pattern: '/**/favicon.ico', access: ['permitAll']]
]
```
