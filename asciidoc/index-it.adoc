== Dal codice allo schermo

Un modulo richiede poche righe di Groovy. I campi sono simboli generati dalla tua classe (`username_`), quindi il compilatore li controlla; i vincoli diventano messaggi di errore localizzati.

[.home-split]
--
[source,groovy]
----
def form() {
    DslSampleUser u = new DslSampleUser()
    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            form createForm(u, {
                row {
                    col {
                        section 'User', {
                            field u.username_
                            field u.firstName_
                            field u.lastName_
                        }
                    }
                    col {
                        section 'Details', {
                            field u.age_
                            field u.birthday_
                            field u.city_
                            field u.status_
                            field u.enabled_
                        }
                    }
                }
                formAction this.&saveForm as MC
            })
        }
    })
}
----

[.home-card]
====
icon:shield[]

*Sicurezza per singolo campo*

Gli oggetti vengono visualizzati e modificati in base ai permessi dell'utente su *ogni campo*. I link e le azioni dei moduli che l'utente non può eseguire vengono nascosti automaticamente.

link:doc/UserGuide/Security-it.adoc[Sicurezza →]
====

[.home-card]
====
icon:file-pdf-o[]

*Un solo DSL, ogni formato di output*

La stessa descrizione genera *HTML*, *PDF*, *email* e *CSV*.

link:doc/DSLs/block-printable-dsl-it.adoc[DSL di stampa →]
====

[.home-card]
====
icon:language[]

*Localizzato e validato*

Le etichette provengono dai file i18n e gli errori di validazione vengono localizzati senza codice aggiuntivo.

link:doc/DSLs/form-dsl-it.adoc#_form_validation[Validazione dei moduli →]
====

[.home-card]
====
icon:table[]

*Filtra, ordina, impagina*

Tabelle e filtri senza scrivere query né mantenere dati in sessione.

link:doc/DSLs/filter-table-dsl-it.adoc[DSL per filtri e tabelle →]
====

[.home-card]
====
icon:search[]

*Ricerca full-text*

Indicizzazione Solr di oggetti di dominio tipizzati staticamente, con faceting e ranking. Le anteprime dei file sono estendibili.

link:more/Search/Search-it.adoc[Ricerca →]
====

[.home-card]
====
icon:database[]

*JDBC sul tuo modello*

link:more/JDBC/taack-jdbc-driver-it.adoc[Driver JDBC Taack →]
====

[.home-card]
====

Un'interfaccia shell in esecuzione nel processo del server e un file system virtuale per utente, con verifica delle credenziali (modulo `taack-ui-ssh`).
