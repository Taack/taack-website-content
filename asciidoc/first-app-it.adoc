= Prima applicazione

== Come funziona l'applicazione con il Taack Framework?

Il tuo progetto intranet è diviso in due parti:

* I plugin dell'applicazione, situati nella cartella `app`, sono micro-progetti, ciascuno con le proprie dipendenze, la propria build, ecc. (ad es., Crew).
Per una spiegazione più approfondita su come vengono dichiarati i plugin, consulta link:doc/plugin/taack-plugin.adoc#_about_plugins[Informazioni sui plugin].
* Il server principale utilizza tutti i plugin dell'applicazione implementati nel suo file `build.gradle` e li visualizza nella pagina principale dell'intranet.

== Creare un nuovo plugin dell'applicazione


Per creare un nuovo plugin dell'applicazione (un modulo Gradle), assicurati di scaricare l'ultima versione della tua intranet dal nostro repository GitHub (vedi link:install.adoc[installazione]).

.Esegui il seguente comando dalla cartella principale della tua intranet:

// setting system properties with the -D flag
// setting project properties with the -P flag

[,bash]
----
$ ./gradlew -DmodName=myBooks server:generateTaackAppTask
----

Questo crea una nuova cartella `app/myBooks`.

[NOTE]
====
Sotto `intranet/app/myBooks/grails-app/domain`, sostituisci la directory `myBooks` con `my.books`, il che garantirà l'accesso alle classi create in `domain` da `controllers` e `services` poiché faranno parte dello stesso package.
====

== Gestire i futuri aggiornamenti

Nella maggior parte dei casi, l'aggiornamento della tua intranet comporterà l'aggiornamento della cartella `buildSrc`, del file `gradle.properties` e, meno frequentemente, dei file `build.gradle` delle applicazioni.

[NOTE]
====
Infatti, questo processo è comune nello sviluppo software a lungo termine e non dovrebbe intimorire i nuovi arrivati.
====

== Creare una tabella

Ora visualizziamo una tabella nella nostra pagina `listBook`. Vai su `grails-app/services/my/books/MyBooksUiService`.

.Crea un nuovo Specifier di tabella chiamato `buildBookTable`:
[,groovy]
----

UiTableSpecifier buildBookTable() {
    Book book = new Book()
    UiTableSpecifier bookTableSpecifier = new UiTableSpecifier()
    bookTableSpecifier.ui {
    //Add table content inside the closure here
    }
}

----
Qui stiamo definendo una nuova tabella che elencherà le istanze di `Book`. Usa `import taack.ui.dsl.UiTableSpecifier`.





.Per definire le intestazioni della tabella aggiungi il seguente codice nella closure (importa le classi necessarie):
[,groovy]
----
bookTableSpecifier.ui {
    // -- Header --
    header {
        column {
            sortableFieldHeader book.title_ //<1>
        }
        column {
            label book.authorName_
        }
        column {
            label book.numberOfPages_
        }
        column {
            label "Delete book"
        }
    }
}
----
<1> Nota che qui usiamo `sortableFieldHeader`, questo rende la colonna ordinabile; puoi ordinare i libri in ordine alfabetico facendo clic sull'intestazione `book.title`.
Ora popoleremo la nostra tabella iterando sulle istanze di `Book` nel database utilizzando il metodo DSL di tabella `iterate`.

.Aggiungi il seguente codice (inizializza e importa le classi necessarie):
[,groovy]
----
bookTableSpecifier.ui {
    //table headers...

    iterate(taackFilterService.getBuilder(Book) // <1>
        .setMaxNumberOfLine(8) // <2>
        .setSortOrder(TaackFilter.Order.DESC, book.title_) // <3>
        .build()) { Book bookIterator ->
    rowColumn {
        rowField bookIterator.title_ // <4>
    }
    rowColumn {
        rowField bookIterator.authorName_
    }
    rowColumn {
        rowField bookIterator.numberOfPages_
    }
    rowColumn {
        rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN, // <5>
            MyBooksController.&deleteBook as MethodClosure, bookIterator.id
        }
    }
}

----
<1> Usa `import taack.domain.TaackFilterService`.
<2> Verranno visualizzati solo i primi otto libri.
<3> Imposta l'ordine di visualizzazione in base al titolo dei libri in ordine decrescente (usa `import taack.domain.TaackFilter`).
<4> Il trattino basso (underscore) è necessario qui.
<5> Usa `import taack.ui.dsl.common.ActionIcon
import taack.ui.dsl.common.IconStyle`.

[NOTE]
====
Dobbiamo creare l'azione `deleteBook`. Per ora la lasceremo vuota.

== Creare un modulo e salvare oggetti

Ora realizzeremo il modulo che verrà utilizzato per creare e aggiornare i libri.
Per gestire entrambi i casi, in `MyBooksUiService` inizializzeremo un nuovo `Book` oppure lo leggeremo se è stato passato un ID `Book` nei parametri della richiesta.

.Crea un nuovo Specifier di modulo chiamato `buildBookForm`:
[,groovy]
----
UiFormSpecifier buildBookForm(Book book) {
    book ?= new Book(params) // <1>
}
----
<1> Ciò significa che se `book` è null, gli viene assegnata una nuova istanza utilizzando i parametri della richiesta.

Ora definiamo il suo modulo e il suo contenuto.

.Aggiungi quanto segue in `buildBookForm` (importa le classi necessarie):
[,groovy]
----
UiFormSpecifier bookFormSpecifier = new UiFormSpecifier()
bookFormSpecifier.ui book, {
    //Section of fields
    section "Book details", {
        field book.title_
        field book.authorName_
        field book.numberOfPages_
    }
    //Save button
    formAction MyBooksController.&saveBook as MethodClosure // <1>
}
----
<1> Dovrai definire l'azione `saveBook` (come per `deleteBook`) in `MyBooksController`.

Usa `import taack.ui.dsl.UiFormSpecifier`.

Una volta definito il modulo, puoi visualizzarlo utilizzando il metodo `taackUiService.show()`.

.Aggiungi quanto segue all'interno del metodo `bookForm` in `MyBooksController`:
[,groovy]
----
def bookForm(Book book) {
    UiFormSpecifier tableFormSpecifier = myBooksUiService.buildBookForm book

    taackUiService.show new UiBlockSpecifier().ui {
        modal {
            form tableFormSpecifier
        }
    }
}
----

Usa `import taack.ui.dsl.UiFormSpecifier`.

Questa volta non specifichiamo `buildMenu` nella chiamata a `show`, poiché non vogliamo che il menu venga renderizzato all'interno della finestra modale.

.Modifica l'azione `saveBook` (importa e inizializza le classi necessarie):

[,groovy]
----
@Transactional
def saveBook() {
    taackSaveService.saveThenReloadOrRenderErrors(Book)
}
----
Usa `import taack.render.TaackSaveService` e `import grails.gorm.transactions.Transactional`.

[NOTE]

Vedi link:doc/DSLs/block-dsl.adoc#_modal_stack_code_sample[Chiudere la modale e ricaricare la pagina] per scoprire come evitare l'uso di `redirectAction` durante il salvataggio...

== Mostrare un oggetto

Ora che possiamo creare libri e vederne un elenco in una tabella, visualizziamo ogni libro più nel dettaglio utilizzando una finestra modale.
Ancora una volta definiamo lo specifier e lo renderizziamo all'interno di un blocco modale utilizzando `taackUiService.show()`.


.Crea `showBook` (importa la classe necessaria):
[,groovy]
----
def showBook(Book book) {
    // Define the show displayed fields
    UiShowSpecifier showSpec = new UiShowSpecifier().ui({
        fieldLabeled book.title_
        fieldLabeled book.authorName_
    })

    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            show showSpec
        }
    })
}
----
Usa `import taack.ui.dsl.UiShowSpecifier`.

Dobbiamo anche visualizzare un link a questa finestra modale nella tabella. Per farlo, aggiungi la seguente riga nella stessa `rowColumn` (sotto il campo del titolo del libro) in cui desideri che appaia il pulsante in `MyBooksUiService`:

.Aggiungi 2 righe in `buildBookTable`:
[,groovy]
----

UiTableSpecifier buildBookTable() {
    //Section of code
    rowColumn {
        //Add these 2 lines
        rowAction ActionIcon.SHOW * IconStyle.SCALE_DOWN, // <1>
        MyBooksController.&showBook as MethodClosure, bookIterator.id
        rowField bookIterator.title_
    }
    //Section of code
}


----

<1> Qui riduciamo la dimensione dell'icona con l'operatore di moltiplicazione.

Questo creerà un _piccolo_ pulsante icona nella cella della tabella che aprirà una finestra modale con le informazioni del libro corrispondente.

Nota che `ActionIcon` è stato moltiplicato per un `IconStyle` per modificarne la dimensione in questo caso.

== Filtro
Se aggiungiamo troppi libri potremmo perdere tempo a cercare un libro specifico; filtrare i libri può rendere la ricerca più efficiente. Implementiamolo in `MyBooksUiService`.


.Crea un nuovo Specifier di filtro chiamato `buildBookFilter`:
[,groovy]
----
UiFilterSpecifier buildBookFilter(Book book) {
    UiFilterSpecifier bookFilterSpecifier = new UiFilterSpecifier() // <1>

    bookFilterSpecifier.ui Book, { // <2>
        section "Book Filter", {  // <3>
            filterField book.title_ // <4>
        }
    }
}
----
<1> Crea il filtro. Usa `import taack.ui.dsl.UiFilterSpecifier`.
<2> Passa la classe dell'oggetto e la closure contenente le specifiche del filtro tramite il metodo `ui`.
<3> Crea una sezione con etichetta "Book Filter".
<4> Aggiungi il campo al filtro, nota il *trattino basso* alla fine del nome del campo.

Il passo successivo consiste nel visualizzare questo filtro appena creato.

.Modifica `taackUiService.show` in `listBook` (situato in `MyBooksController`):
[,groovy]
----
def listBook() {
    Book book = new Book()
    UiTableSpecifier tableBookSpecifier = myBooksUiService.buildBookTable()
    UiFilterSpecifier filterBookSpecifier = myBooksUiService.buildBookFilter book

    taackUiService.show(new UiBlockSpecifier().ui {
        tableFilter filterBookSpecifier, tableBookSpecifier, {
            menuIcon ActionIcon.CREATE, this.&bookForm as MethodClosure
        }
    }, MyBooksUiService.buildMenu())
}
----
Usa `import taack.ui.dsl.UiFilterSpecifier`.

== Risoluzione dei problemi ed errori comuni

.Output di errore:
[source,console]
----
ERROR: Cannot resolve symbol 'MyBooksUiService'
----
Hai dimenticato di ricaricare Gradle dopo aver creato il plugin. Fai clic sul pulsante di ricarica di Gradle nel tuo IDE.

.Output di errore:
[,console]
----
ERROR:  Field 'authorName_' not found
----
Hai rinominato il campo `authorName` in `author` (un riferimento ad `Author`). Assicurati di aver modificato tutti gli `authorName_` in `author_` sia nel modulo che nella tabella.

.Output di errore:
[,console]
----
ERROR: No matching method for action...
----
Assicurati di aver dichiarato il metodo corrispondente in `MyBooksController` e di aver utilizzato correttamente la sintassi `MethodClosure`: `MyBooksController.&myMethod as MethodClosure`.


.Il modulo viene visualizzato ma non salva:
Potrebbe mancare l'annotazione `@Transactional` nel metodo `saveBook` oppure hai dimenticato di importare `taackSaveService`.

.Errore del database dopo aver rinominato i campi:
Se hai modificato i campi nelle classi di dominio, devi eliminare i file del database:
`intranet/server/intranetDb.mv.db`
`intranet/server/intranetDb.trace.db`. Fai attenzione, poiché questo cancellerà tutti i dati salvati in precedenza.

.Il connettore del database non esegue il flush della transazione:

Potresti utilizzare l'annotazione `@Transactional` sbagliata. Assicurati di utilizzare quella del package GORM e non quella di Javax.

.Accedere alla console del database H2:

Potresti voler controllare l'integrità dei dati e i DDL generati dal database H2 integrato.

Per farlo devi modificare le impostazioni di Spring Security.

Naviga verso
Root → /server → /grails-app → /conf

Troverai un file `application.groovy`.

Aggiungi

```groovy
[pattern: '/h2-console/**',  access: ['permitAll']],
```
