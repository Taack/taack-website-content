== Vom Code zum Bildschirm

Ein Formular besteht aus wenigen Zeilen Groovy. Felder sind Symbole, die aus Ihrer Klasse generiert werden (`username_`), sodass der Compiler sie prüft; Constraints werden zu lokalisierten Fehlermeldungen.

[.home-split]
--
[source,groovy]
----
def form() {
    DslSampleUser u = new DslSampleUser()
    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            form createForm(u, {
                row {
                    col {
                        section 'User', {
                            field u.username_
                            field u.firstName_
                            field u.lastName_
                        }
                    }
                    col {
                        section 'Details', {
                            field u.age_
                            field u.birthday_
                            field u.city_
                            field u.status_
                            field u.enabled_
                        }
                    }
                }
                formAction this.&saveForm as MC
            })
        }
    })
}
----
