[[filterFieldExpressionReverse]]
.Nouveau filtre filterFieldExpressionReverse
====
.Filtre filterFieldExpressionReverse
[source,groovy]
----
def parentParts() {
    UiFilterSpecifier f = new UiFilterSpecifier().sec PlmFreeCadPart, {         <1>
        PlmFreeCadLink link = new PlmFreeCadLink()
        filterFieldExpressionReverse(link.part_,                                <2>
                true,                                                           <3>
                new FilterExpression(null as Object, Operator.NE, link.part_))  <4>
    }
    taackUiService.show(new UiBlockSpecifier().ui {
        tableFilter(plmFreeCadUiService.buildPartFilter(), plmFreeCadUiService.buildPartTable(null, f), {
            menuIcon ActionIcon.GRAPH, this.&model as MC
        })
    }, buildMenu())
}
----
<1> Nous construisons un filtre pour `PlmFreeCadPart`
<2> Nous souhaitons lister les assemblages parents, ceux pour lesquels le champ `PlmFreeCadLink part` ne pointe pas vers le `PlmFreeCadPart` listé
<3> `true` correspond à `notIn`
<4> Littéralement : nous voulons tous les *PlmFreeCadPart* qui ne sont pas des enfants

.HQL généré
[source,hql]
----
select
    distinct sc  ,sc.dateCreated
from PlmFreeCadPart sc
where
    sc.id NOT IN (select auo.part.id from PlmFreeCadLink auo where auo.part IS NOT NULL)    <1>
    and sc.nextVersion IS NULL
order by sc.dateCreated DESC
----

<1> Clause `where` ajoutée par l'expression `filterFieldExpressionReverse`

[[show-grid-layout]]
.Disposition Show en grille (Grid Layout)
====

.Disposer un Show sur une grille adaptative via `ShowLayout.GRID`
[source,groovy]
----
new UiShowSpecifier().ui ShowLayout.GRID, {                      <1>
    fieldLabeled item.ref_
    fieldLabeled item.name_
    fieldLabeled item.itemStatus_
    fieldLabeled item.gtin_
    fieldLabeled Style.SPAN_TWO, item.labeling_                  <2>
    fieldLabeled Style.BOLD + Style.SPAN_FULL, item.description_ <3>
}
----

<1> Passer `ShowLayout.GRID` pour disposer les champs sur une grille à ajustement automatique au lieu de verticalement dans une colonne. La valeur par défaut est `ShowLayout.LIST`.
<2> Chaque champ occupe une cellule de grille par défaut. `Style.SPAN_TWO` / `Style.SPAN_THREE` peuvent être utilisés pour permettre aux cellules de s'étendre sur plusieurs colonnes.
<3> `Style.SPAN_FULL` fait s'étendre un champ sur toute la ligne. Les étendues se combinent avec n'importe quel autre style via `+` (ici avec `Style.BOLD`).

Notez que la grille ajuste automatiquement autant de colonnes que la largeur du conteneur le permet, chacune d'au moins `220px` de large (`grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))` sur la classe `taackShowGrid`, le minimum pouvant être redéfini dans votre CSS).

== Version 0.7.0

* Grails 7, Gradle 8.4, Java 24, Groovy 4.0.28 ...
* Amélioration des performances : démarrage plus tôt de la transmission de la page et consommation mémoire réduite par page
* Découpage de `taack-ui` en `taack-ui`, `taack-ui-jdbc`, `taack-ui-pdf`, `taack-ui-ssh`, `taack-ui-search`, `taack-ui-asciidoc`. Un serveur minimal utilisant uniquement `taack-ui` devrait produire un Jar d'environ 70 Mo

* `TaackUiConfiguration` n'est plus initialisé via `application.yml`, ses membres sont statiques et peuvent être modifiés dans `server/grails-app/init/.../Application.groovy` (voir <<taack-ui-configuration>>)
* Il est désormais possible d'être rappelé lors d'un événement de glisser-déposer (drop) sur un tableau ou une cellule de tableau (voir <<drop-on-table>>, <<drop-on-cell>>)
