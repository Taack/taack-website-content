== 从代码到界面

只需几行 Groovy 代码即可定义一个表单。字段是由您的类生成的符号（如 `username_`），因此编译器会对其进行检查；约束条件会自动转化为本地化的错误消息。

[.home-split]
--
[source,groovy]
----
def form() {
    DslSampleUser u = new DslSampleUser()
    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            form createForm(u, {
                row {
                    col {
                        section 'User', {
                            field u.username_
                            field u.firstName_
                            field u.lastName_
                        }
                    }
                    col {
                        section 'Details', {
                            field u.age_
                            field u.birthday_
                            field u.city_
                            field u.status_
                            field u.enabled_
                        }
                    }
                }
                formAction this.&saveForm as MC
            })
        }
    })
}
----

== 功能特性

[.home-grid]
--
[.home-card]
====
icon:shield[]

*字段级安全控制*

根据用户在*每个字段*上的权限来显示和编辑对象。用户无权执行的链接和表单操作会自动隐藏。

link:doc/UserGuide/Security.adoc[安全控制 →]
====

[.home-card]
====
icon:file-pdf-o[]

*一种 DSL，多种输出*

同一份界面描述可同时渲染为 *HTML*、*PDF*、*邮件*和 *CSV*。

link:doc/DSLs/block-printable-dsl.adoc[打印 DSL →]
====

[.home-card]
====
icon:language[]

*本地化与数据校验*

标签来自 i18n 国际化文件，校验错误无需编写额外代码即可实现本地化显示。

link:doc/DSLs/form-dsl.adoc#_form_validation[表单校验 →]
====

[.home-card]
====
icon:table[]

*过滤、排序与分页*

无需编写查询语句或维护会话数据，即可实现表格与过滤器。

link:doc/DSLs/filter-table-dsl.adoc[过滤器与表格 DSL →]
====

[.home-card]
====
icon:search[]

*全文检索*

对静态类型的领域对象进行 Solr 索引，支持分面搜索与结果排序，并可扩展文件预览功能。

link:more/Search/Search.adoc[全文检索 →]
====

[.home-card]
====
icon:database[]

*模型上的 JDBC*

在 IntelliJ、DBeaver 或 LibreOffice Base 中使用 TQL（Taack 查询语言）查询领域对象。

link:more/JDBC/taack-jdbc-driver.adoc[Taack JDBC 驱动 →]
====

[.home-card]
====
icon:terminal[]

*SSH 与 SFTP*

在服务器进程内运行的 Shell 界面，以及按用户隔离并带有凭据校验的虚拟文件系统（`taack-ui-ssh` 模块）。

link:app/Intercom.adoc[Intercom →]
