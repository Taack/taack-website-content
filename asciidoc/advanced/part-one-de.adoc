.Implementieren Sie eine Klasse `MyLibraryAuthor` (TODO 1.1):
[,groovy]
----
import grails.compiler.GrailsCompileStatic
import taack.ast.annotation.TaackFieldEnum

@GrailsCompileStatic
@TaackFieldEnum
class MyLibraryAuthor {
    String firstName
    String lastName
    Date dateOfBirth
    List<MyLibraryBook> listOfBooks //<1>
    Boolean isActive = true //<2>

    static constraints = {}

    static hasMany = [listOfBooks: MyLibraryBook] //<3>

    String toString() {
        return firstName + ' ' + lastName
    }
}
----
<1> `Books`, die von diesem `Author` geschrieben wurden, werden in `listOfBooks` gespeichert.
<2> `isActive` ermöglicht das logische Löschen (Soft Delete).
<3> `hasMany` ist ein GORM-Assoziationsschlüsselwort, mit dem wir eine Eins-zu-viele-Beziehung zwischen Domänenklassen definieren können. Es wird verwendet, um zugehörige Sammlungen (wie eine Liste von Büchern, die zu einem Autor gehören) automatisch zu verwalten. Weitere Informationen finden Sie in der GORM-Dokumentation.

[,groovy]
----
UiFilterSpecifier buildIsActiveAuthorFilter(MyLibraryAuthor author) {
    UiFilterSpecifier isActiveAuthorFilter = new UiFilterSpecifier()
    isActiveAuthorFilter.ui MyLibraryAuthor, {
        section "Filter", {
            filterFieldExpressionBool "Is Active", new FilterExpression(true, Operator.EQ, author.isActive_) //<1>
        }
    }
}
----
<1> Wir erstellen eine `FilterExpression`, die einen Wert, einen Operator und ein `FieldInfo` entgegennimmt.

Es stehen verschiedene Operatoren zur Verfügung:

- IN: in einer Liste von Werten,
- NI: nicht in einer Liste von Werten,
- EQ: gleich einem anderen Wert,
- NE: ungleich einem anderen Wert,
- LT: kleiner als ein anderer Wert,
- IL: ähnlich wie ein anderer Wert (is like),
- GT: größer als ein anderer Wert,
- IS_EMPTY: ist leer

UiTableSpecifier buildInstanceBookTable(
    MyLibraryBook book,
    MyLibraryBookInstance bookInstance = null) {
    UiTableSpecifier table = new UiTableSpecifier()
    table.ui {
        header {
            label "Serial Number"
            column {label "Delete"}
        }

        TaackFilter.FilterBuilder filter = taackFilterService
            .getBuilder(MyLibraryBookInstance)
            .addRestrictedIds(book.listOfBookInstance*.id as Long[])

        filter.addFilter(buildIsActiveBookInstances(book))

        iterate(filter.build()) { MyLibraryBookInstance bookInstanceIterator ->
            rowField bookInstanceIterator.serialNumber_
            rowColumn {
                rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN,
                    MyLibraryController.&deleteBookInstances as MC,
                    bookInstanceIterator.id, [bookId:book.id]
            }
        }
    }
}

@Transactional
def deleteBookInstances(MyLibraryBookInstance bookInstance) {
    MyLibraryBook book = MyLibraryBook.get(params.long('bookId'))
    UiTableSpecifier bookInstanceTable = myLibraryUiService.buildInstanceBookTable(book)

    bookInstance.isActive = false

    taackUiService.show new UiBlockSpecifier().ui {
        closeModalAndUpdateBlock { //<1>
            tableFilter(
                    myLibraryUiService.buildBookFilter(), //<2>
                    myLibraryUiService.buildBookTable(), //<2>
            ) {
                menuIcon ActionIcon.CREATE, this.&createBook as MethodClosure //<2>
            }
            modal {
                table bookInstanceTable //<3>
            }
        }
    }
}

<1> Die Verwendung von `closeModalAndUpdateBlock` ermöglicht es dem Benutzer, den aktualisierten Status der gelöschten `BookInstance` sofort zu sehen. Es schließt den Modal-Dialog unmittelbar nachdem der Benutzer eine `BookInstance` ausgewählt hat.
<2> Wir rufen die Builder auf, die zum Anzeigen der Bücher verwendet werden, damit `numberOfInstances` in der Büchertabelle aktualisiert wird, wenn wir den Modal-Dialog schließen.
<3> Wir öffnen erneut einen Modal-Dialog. Wenn der Benutzer eine `BookInstance` auswählt, wird der Modal-Dialog geschlossen und anschließend wieder geöffnet, sodass die ausgewählte `BookInstance` nicht mehr angezeigt wird.
