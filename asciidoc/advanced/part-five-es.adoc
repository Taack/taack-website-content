== Creación de archivos PDF

En esta sección, aprenderá a crear archivos PDF basados en los datos de su proyecto.

Para crear un PDF, utilizará un `UiPrintableSpecifier()`, compuesto por:

- `printableHeader`: permite definir un encabezado que se repetirá en todas las páginas.
- `printableBody`: permite definir el contenido del PDF a lo largo de varias páginas.
- `printableFooter`: permite definir el pie de página que se repetirá en todas las páginas (el tamaño no debe ser superior a 2 cm).

Si desea ver un ejemplo, consulte link:doc/DSLs/block-printable-dsl-es.adoc[DSL de bloques imprimibles (Printable Block DSL)].

=== Encabezado imprimible (Printable Header)

El parámetro de altura es obligatorio si necesita una altura diferente a 2 cm.

Existen tres opciones para organizar la visualización del encabezado:

- `printableHeaderLeft`: dibujará de izquierda a derecha
- `printableHeader`: deberá especificar la ubicación (centro, izquierda, derecha)
- `printableHeaderRight`: dibujará de derecha a izquierda

Dentro del encabezado, se dibuja el contenido utilizando `UiSpecifier`.

.Código de ejemplo:
[,groovy]
----
printableHeaderRight('7.5cm') { //<1>
    show new UiShowSpecifier().ui {
        field'Content'
    }, BlockSpec.Width.MAX
}
----
<1> dibuja el encabezado comenzando por la derecha con una altura de 7,5 cm.

Vamos a implementar nuestro propio `printableHeader`, donde dibujaremos el nombre del usuario que solicita el PDF, el logotipo de Taack y la fecha en que se solicita el PDF.

Vaya a `MyLibraryUiService`.

=== Cuerpo imprimible (Printable Body)

Dentro del cuerpo, se dibuja el contenido utilizando `UiSpecifier`, igual que en el `printableHeader`.

1. Queremos mostrar todos los nombres de los autores con una tabla debajo que muestre los libros escritos por cada autor específico.
2. También queremos mostrar los gráficos que implementamos anteriormente.
3. Finalmente, si el usuario que solicita el PDF es un prestatario, queremos mostrar en una tabla la lista de solicitudes de préstamos de libros que ya han sido devueltos.

=== Pie de página imprimible (Printable Footer)

Dentro del pie de página, se dibuja el contenido utilizando `UiSpecifier`, igual que en el `printableHeader`.
Muestra automáticamente el número de página en la esquina inferior derecha.
Para evitar redundancias, no mostraremos nada adicional en el `printableFooter`.

== Renderizado del PDF

Se ha añadido un botón al menú que muestra un botón `export_pdf` que llama a `downloadLibraryPdf`, lo que permitirá crear y descargar el PDF. Implementemos este método.

Vaya a `MyLibraryController`.

Modo Pro: implemente `downloadBinLibraryPdf` [TODO 2].

.Implemente `downloadBinLibraryPdf`:
[,groovy]
----
def downloadBinLibraryPdf() {
    UiPrintableSpecifier pdf = myLibraryUiService.buildLibraryPdf()
    taackUiPdfService.downloadPdf(pdf, 'LibrarySummary', false)
}
----

====
Cualquier método utilizado para crear un PDF *tiene* que empezar por *downloadBin*
