.Implemente una clase `MyLibraryAuthor` (TODO 1.1):
[,groovy]
----
import grails.compiler.GrailsCompileStatic
import taack.ast.annotation.TaackFieldEnum

@GrailsCompileStatic
@TaackFieldEnum
class MyLibraryAuthor {
    String firstName
    String lastName
    Date dateOfBirth
    List<MyLibraryBook> listOfBooks //<1>
    Boolean isActive = true //<2>

    static constraints = {}

    static hasMany = [listOfBooks: MyLibraryBook] //<3>

    String toString() {
        return firstName + ' ' + lastName
    }
}
----
<1> Los `Books` escritos por este `Author` se almacenarán en `listOfBooks`.
<2> `isActive` permitirá el borrado lógico (soft delete).
<3> `hasMany` es una palabra clave de asociación de GORM que nos permite definir una relación de uno a muchos entre clases de dominio. Se utiliza para gestionar automáticamente colecciones relacionadas (como una lista de libros pertenecientes a un autor). Para obtener más información, consulte la documentación de GORM.

UiFilterSpecifier buildIsActiveAuthorFilter(MyLibraryAuthor author) {
    UiFilterSpecifier isActiveAuthorFilter = new UiFilterSpecifier()
    isActiveAuthorFilter.ui MyLibraryAuthor, {
        section "Filter", {
            filterFieldExpressionBool "Is Active", new FilterExpression(true, Operator.EQ, author.isActive_) //<1>
        }
    }
}
----
<1> Creamos una `FilterExpression` que recibe un valor, un operador y un `FieldInfo`.

Hay diferentes operadores disponibles:

- IN: en una lista de valores,
- NI: no está en una lista de valores,
- EQ: igual a otro valor,
- NE: distinto de otro valor,
- LT: menor que otro valor,
- IL: similar a otro valor (is like),
- GT: mayor que otro valor,
- IS_EMPTY: está vacío
