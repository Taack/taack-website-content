== Configurazione
=== Clonazione dell'Intranet pronta per lo sviluppo

.Clona il repository iniziale:

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
$ cd intranet/app/
$ git clone https://github.com/Taack/myLibrary.git
$ cd myLibrary
----

Questo clonerà l'intranet e successivamente lo scheletro dell'applicazione myLibrary che creeremo qui.
