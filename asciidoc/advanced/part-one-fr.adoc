== Introduction

Nous allons commencer par créer une bibliothèque privée simple, où l'utilisateur peut créer des auteurs, des livres et des exemplaires de livres (inspiré du projet précédent décrit dans Utilisation).

.Tableau des livres
image::part-one-screenshot.webp[Reload,width=800,align="left"]

Nous avons déjà implémenté une partie du code pour vous dans `myLibrary`. Pour ce tutoriel, vous avez deux options : vous pouvez soit suivre l'implémentation étape par étape fournie ici, soit essayer d'implémenter chaque étape par vous-même d'abord, puis vérifier votre implémentation ensuite. L'explication de chaque méthode est répartie entre cette documentation et `myLibrary`.

*Mode Pro :* Un mode plus exigeant destiné aux utilisateurs expérimentés. Vous êtes encouragé à tenter les implémentations de manière autonome, en ne consultant les exemples fournis qu'en cas de besoin.

.Implémentez une classe `MyLibraryAuthor` (TODO 1.1) :
[,groovy]
----
import grails.compiler.GrailsCompileStatic
import taack.ast.annotation.TaackFieldEnum

@GrailsCompileStatic
@TaackFieldEnum
class MyLibraryAuthor {
    String firstName
    String lastName
    Date dateOfBirth
    List<MyLibraryBook> listOfBooks //<1>
    Boolean isActive = true //<2>

    static constraints = {}

    static hasMany = [listOfBooks: MyLibraryBook] //<3>

    String toString() {
        return firstName + ' ' + lastName
    }
}
----
<1> Les `Books` écrits par cet `Author` seront stockés dans `listOfBooks`.
<2> `isActive` permettra la suppression logique (soft delete).
<3> `hasMany` est un mot-clé d'association GORM qui permet de définir une relation un-à-plusieurs entre des classes de domaine. Il est utilisé pour gérer automatiquement les collections associées (comme une liste de livres appartenant à un auteur). Pour plus d'informations, consultez la documentation GORM.

.Implémentez une classe `MyLibraryBook` (TODO 1.2) :
[,groovy]
----
import grails.compiler.GrailsCompileStatic
import taack.ast.annotation.TaackFieldEnum

@GrailsCompileStatic
@TaackFieldEnum
class MyLibraryBook {
    String title
    MyLibraryAuthor author
    String description
    int numberOfPages
    List<MyLibraryBookInstance> listOfBookInstance //<1>
    int count = 0

    static constraints = {}

    static hasMany = [listOfBookInstance: MyLibraryBookInstance]

    int getNumberOfInstances() {
        if (!listOfBookInstance) { return 0}
        count = listOfBookInstance.count {it.isActive} as int
        return count

}

[,groovy]
----
UiFilterSpecifier buildIsActiveAuthorFilter(MyLibraryAuthor author) {
    UiFilterSpecifier isActiveAuthorFilter = new UiFilterSpecifier()
    isActiveAuthorFilter.ui MyLibraryAuthor, {
        section "Filter", {
            filterFieldExpressionBool "Is Active", new FilterExpression(true, Operator.EQ, author.isActive_) //<1>
        }
    }
}
----
<1> Nous créons une `FilterExpression` qui prend une valeur, un opérateur et un `FieldInfo`.

Différents opérateurs sont disponibles :

- IN : dans une liste de valeurs,
- NI : pas dans une liste de valeurs,
- EQ : égal à une autre valeur,
- NE : différent d'une autre valeur,
- LT : inférieur à une autre valeur,
- IL : semblable à une autre valeur (is like),
- GT : supérieur à une autre valeur,
- IS_EMPTY : est vide

UiTableSpecifier buildInstanceBookTable(
    MyLibraryBook book,
    MyLibraryBookInstance bookInstance = null) {
    UiTableSpecifier table = new UiTableSpecifier()
    table.ui {
        header {
            label "Serial Number"
            column {label "Delete"}
        }

            .getBuilder(MyLibraryBookInstance)
            .addRestrictedIds(book.listOfBookInstance*.id as Long[])

        filter.addFilter(buildIsActiveBookInstances(book))

        iterate(filter.build()) { MyLibraryBookInstance bookInstanceIterator ->
            rowField bookInstanceIterator.serialNumber_
            rowColumn {
                rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN,
                    MyLibraryController.&deleteBookInstances as MC,
                    bookInstanceIterator.id, [bookId:book.id]
            }
        }
    }

def deleteBookInstances(MyLibraryBookInstance bookInstance) {
