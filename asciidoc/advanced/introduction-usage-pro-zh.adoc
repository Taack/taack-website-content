== 环境准备
=== 克隆开箱即用的开发环境 Intranet

.克隆初始仓库：

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
$ cd intranet/app/
$ git clone https://github.com/Taack/myLibrary.git
$ cd myLibrary
----

这将克隆 intranet，然后克隆我们将在此处创建的 myLibrary 应用的骨架代码。
