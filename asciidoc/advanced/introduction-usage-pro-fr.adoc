== Configuration
=== Clonage de l'Intranet prêt pour le développement

.Clonez le dépôt de démarrage :

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
$ cd intranet/app/
$ git clone https://github.com/Taack/myLibrary.git
$ cd myLibrary
----

Cela clonera l'intranet puis le squelette de l'application myLibrary que nous allons créer ici.
