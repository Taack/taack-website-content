= Primera aplicación

== ¿Cómo funciona la aplicación con el framework Taack?

Su proyecto de intranet consta de dos partes:

* Los plugins de aplicación, ubicados en la carpeta `app`, son microproyectos, cada uno con sus propias dependencias, compilación, etc. (p. ej., Crew).
Para una explicación más detallada sobre cómo se declaran los plugins, consulte link:doc/plugin/taack-plugin-es.adoc#_about_plugins[Acerca de los plugins].
* El servidor principal utiliza todos los plugins de aplicación implementados en su archivo `build.gradle` y los muestra en la página principal de la intranet.

== Crear un nuevo plugin de aplicación


Para crear un nuevo plugin de aplicación (un módulo de Gradle), asegúrese de obtener la última versión de su intranet desde nuestro repositorio de GitHub (consulte link:install-es.adoc[instalación]).

.Ejecute el siguiente comando desde la carpeta raíz de su intranet:

// setting system properties with the -D flag
// setting project properties with the -P flag

[,bash]
----
$ ./gradlew -DmodName=myBooks server:generateTaackAppTask
----

Esto crea una nueva carpeta `app/myBooks`.

[NOTE]
====
Bajo `intranet/app/myBooks/grails-app/domain`, reemplace el directorio `myBooks` por `my.books`, lo que garantizará el acceso a las clases creadas en `domain` desde `controllers` y `services`, ya que formarán parte del mismo paquete.
====

== Gestionar futuras actualizaciones

La mayoría de las veces, actualizar su intranet implicará actualizar la carpeta `buildSrc`, el archivo `gradle.properties` y, con menos frecuencia, los archivos `build.gradle` de las aplicaciones.

[NOTE]
====
De hecho, este proceso es habitual en el desarrollo de software a largo plazo y no debería intimidar a los recién llegados.
====

== Crear una tabla

Ahora mostremos una tabla en nuestra página `listBook`. Vaya a `grails-app/services/my/books/MyBooksUiService`.

.Cree un nuevo especificador de tabla llamado `buildBookTable`:
[,groovy]
----

UiTableSpecifier buildBookTable() {
    Book book = new Book()
    UiTableSpecifier bookTableSpecifier = new UiTableSpecifier()
    bookTableSpecifier.ui {
    //Add table content inside the closure here
    }
}

----
Aquí estamos definiendo una nueva tabla que listará instancias de `Book`. Utilice `import taack.ui.dsl.UiTableSpecifier`.





.Para definir los encabezados de la tabla, añada el siguiente código en el closure (importe las clases necesarias):
[,groovy]
----
bookTableSpecifier.ui {
    // -- Header --
    header {
        column {
            sortableFieldHeader book.title_ //<1>
        }
        column {
            label book.authorName_
        }
        column {
            label book.numberOfPages_
        }
        column {
            label "Delete book"
        }
    }
}
----
<1> Observe que aquí usamos `sortableFieldHeader`; esto hace que la columna sea ordenable, por lo que puede ordenar los libros alfabéticamente haciendo clic en el encabezado `book.title`.
Ahora vamos a poblar nuestra tabla iterando sobre las instancias de `Book` en la base de datos mediante el método DSL de tablas `iterate`.

.Añada el siguiente código (inicialice e importe las clases necesarias):
[,groovy]
----
bookTableSpecifier.ui {
    //table headers...

    iterate(taackFilterService.getBuilder(Book) // <1>
        .setMaxNumberOfLine(8) // <2>
        .setSortOrder(TaackFilter.Order.DESC, book.title_) // <3>
        .build()) { Book bookIterator ->
    rowColumn {
        rowField bookIterator.title_ // <4>
    }
    rowColumn {
        rowField bookIterator.authorName_
    }
    rowColumn {
        rowField bookIterator.numberOfPages_
    }
    rowColumn {
        rowAction ActionIcon.DELETE * IconStyle.SCALE_DOWN, // <5>
            MyBooksController.&deleteBook as MethodClosure, bookIterator.id
        }
    }
}

----
<1> Utilice `import taack.domain.TaackFilterService`.
<2> Solo se mostrarán los primeros ocho libros.
<3> Establece el orden de visualización según el título de los libros en orden descendente (utilice `import taack.domain.TaackFilter`).
<4> El guion bajo es necesario aquí.
<5> Utilice `import taack.ui.dsl.common.ActionIcon
import taack.ui.dsl.common.IconStyle`.

[NOTE]
====
Necesitamos crear la acción `deleteBook`. Por ahora, la dejaremos vacía.
====

Vaya a `grails-app/controllers/my/books/MyBooksController.groovy`.

.Añada el siguiente método después de la acción `index`:

----
def deleteBook () {}

== Crear un formulario y guardar objetos

Ahora vamos a crear el formulario que se utilizará para crear y actualizar libros.
Para gestionar ambos casos, vamos a inicializar un nuevo `Book` o leerlo si se ha pasado un ID de `Book` en los parámetros de la petición en `MyBooksUiService`.

.Cree un nuevo especificador de formulario llamado `buildBookForm`:
[,groovy]
----
UiFormSpecifier buildBookForm(Book book) {
    book ?= new Book(params) // <1>
}
----
<1> Esto significa que si `book` es null, se le asigna una nueva instancia usando los parámetros de la petición.

Ahora definimos su formulario y contenido.

.Añada lo siguiente en `buildBookForm` (importe las clases necesarias):
[,groovy]
----

bookFormSpecifier.ui book, {
    //Section of fields
    section "Book details", {
        field book.title_
        field book.authorName_
        field book.numberOfPages_
    }
    //Save button
    formAction MyBooksController.&saveBook as MethodClosure // <1>
}
----
<1> Tendrá que definir la acción `saveBook` (igual que `deleteBook`) en `MyBooksController`.

Utilice `import taack.ui.dsl.UiFormSpecifier`.

Una vez definido su formulario, puede mostrarlo usando el método `taackUiService.show()`.

.Añada lo siguiente dentro del método `bookForm` en `MyBooksController`:
[,groovy]
----
def bookForm(Book book) {
    UiFormSpecifier tableFormSpecifier = myBooksUiService.buildBookForm book

    taackUiService.show new UiBlockSpecifier().ui {
        modal {
            form tableFormSpecifier
        }
    }
}
----

Utilice `import taack.ui.dsl.UiFormSpecifier`.

Esta vez no especificamos `buildMenu` en nuestro `show` ya que no queremos que el menú se renderice dentro de la ventana modal.

.Modifique la acción `saveBook` (importe e inicialice las clases necesarias):

Utilice `import taack.render.TaackSaveService` e `import grails.gorm.transactions.Transactional`.

== Mostrar un objeto

Ahora que podemos crear libros y ver una lista de ellos en una tabla, mostremos cada libro con más detalle usando una ventana modal.
Una vez más definimos el especificador y lo renderizaremos dentro de un bloque modal usando `taackUiService.show()`.


.Cree `showBook` (importe la clase necesaria):
[,groovy]
----
def showBook(Book book) {
    // Define the show displayed fields
    UiShowSpecifier showSpec = new UiShowSpecifier().ui({
        fieldLabeled book.title_
        fieldLabeled book.authorName_
    })

    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            show showSpec
        }
    })
}
----
Utilice `import taack.ui.dsl.UiShowSpecifier`.

También necesitamos mostrar un enlace a esta ventana modal en la tabla. Para ello, añada la siguiente línea en la misma `rowColumn` (debajo del campo del título del libro) donde desea que aparezca el botón en `MyBooksUiService`:

.Añada 2 líneas en `buildBookTable`:
[,groovy]
----

UiTableSpecifier buildBookTable() {
    //Section of code
    rowColumn {
        //Add these 2 lines
        rowAction ActionIcon.SHOW * IconStyle.SCALE_DOWN, // <1>
        MyBooksController.&showBook as MethodClosure, bookIterator.id
        rowField bookIterator.title_
    }
    //Section of code
}


----

<1> Aquí reducimos el tamaño del icono con el operador de multiplicación.

Esto creará un _pequeño_ botón con icono en la celda de la tabla que abrirá una ventana modal con la información del libro correspondiente.

== Filtrado

UiFilterSpecifier buildBookFilter(Book book) {

    bookFilterSpecifier.ui Book, { // <2>
        section "Book Filter", {  // <3>
            filterField book.title_ // <4>
        }
    }
}
----

<2> Pase la clase del objeto y el closure que contiene las especificaciones del filtro mediante el método `ui`.

<4> Añada el campo al filtro; observe el *guion bajo* al final del nombre del campo.

== Solución de problemas y errores comunes

.Salida de error:
[source,console]
----
ERROR: Cannot resolve symbol 'MyBooksUiService'
----
Olvidó recargar Gradle después de crear el plugin. Haga clic en el botón de recarga de Gradle en su IDE.

.Salida de error:
[,console]
----
ERROR:  Field 'authorName_' not found
----
Renombró el campo `authorName` a `author` (una referencia a `Author`). Asegúrese de haber cambiado todos los `authorName_` por `author_` tanto en el formulario como en la tabla.

.Salida de error:
[,console]
----
ERROR: No matching method for action...
----
Asegúrese de haber declarado el método correspondiente en `MyBooksController` y de haber utilizado correctamente la sintaxis de `MethodClosure`: `MyBooksController.&myMethod as MethodClosure`.


.El formulario se muestra pero no guarda:
Es posible que le falte la anotación `@Transactional` en el método `saveBook` o que haya olvidado importar `taackSaveService`.

.Error de base de datos después de renombrar campos:
Si cambió campos en clases de dominio, debe eliminar los archivos de la base de datos:
`intranet/server/intranetDb.mv.db`
`intranet/server/intranetDb.trace.db`. Tenga cuidado, ya que esto borrará todos los datos guardados anteriormente.

.El conector de base de datos no vacía (flush) la transacción:

Es posible que esté utilizando la anotación `@Transactional` incorrecta. Tenga en cuenta que debe usar la del paquete GORM y no la de Javax.

.Acceder a la consola de base de datos H2:

Es posible que desee comprobar la integridad de los datos y los DDL generados por la base de datos H2 integrada.

Para ello, debe ajustar la configuración de Spring Security.

Navegue hasta
Root → /server → /grails-app → /conf

Encontrará un archivo `application.groovy`.

Añada

```groovy
[pattern: '/h2-console/**',  access: ['permitAll']],
```
a este bloque de configuración:
```groovy
grails.plugin.springsecurity.controllerAnnotations.staticRules = [
	[pattern: '/',               access: ['permitAll']],
	[pattern: '/error',          access: ['permitAll']],
	[pattern: '/index',          access: ['permitAll']],
	[pattern: '/index.gsp',      access: ['permitAll']],
	[pattern: '/shutdown',       access: ['permitAll']],
	[pattern: '/assets/**',      access: ['permitAll']],
	[pattern: '/**/js/**',       access: ['permitAll']],
	[pattern: '/**/css/**',      access: ['permitAll']],
	[pattern: '/**/images/**',   access: ['permitAll']],
	[pattern: '/**/favicon.ico', access: ['permitAll']]
]
```
