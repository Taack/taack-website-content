= Installationsanleitung

== Voraussetzungen

Stellen Sie vor Beginn sicher, dass die folgenden Werkzeuge auf Ihrem Rechner installiert sind:

* *Java* (JDK 25 ...)
* *Git*
* https://github.com/unoconv/unoserver[unoserver]

=== Voraussetzungen installieren

==== macOS (Homebrew)

.JDK 24 und Git über Homebrew installieren
[source,bash]
----
$ brew install openjdk@25
$ brew install git
----

==== Windows (Winget)

.JDK 25 und Git über Winget installieren
[source,bash]
----
winget install --id Microsoft.OpenJDK.25
winget install --id Git.Git
----

== Klonen des entwicklungsbereiten Intranets

.Klonen Sie das Starter-Repository:

[source,bash]
----
$ git clone https://github.com/Taack/intranet.git
----

Dieses Repository enthält ein minimales Intranet-Grundgerüst (Crew-Benutzerverwaltung + *Spring Security Plugin*), das sofort für die Entwicklung bereit ist.


== Starten Sie Ihr Intranet

.Wechseln Sie in das neu geklonte Intranet-Verzeichnis und starten Sie den Server:

[source,bash]
----
$ cd intranet
$ ./gradlew server:bootRun
----

[NOTE]
====
Der Befehl `./gradlew` verwendet den Gradle Wrapper, sodass Sie Gradle nicht manuell installieren müssen.
====

.Sobald der Build abgeschlossen ist, sollten Sie Folgendes sehen:
[source,bash]
----
Grails application running at http://localhost:9442
----

Um das Standard-Administratorpasswort zu ändern, bearbeiten Sie die folgenden Dateien:

* `server/grails-app/conf/application.yml`
* `server/grails-app/conf/application-MACOSX.yml`

Suchen Sie nach der Zeile:
[source,yaml]
taack.admin.password: ChangeIt

Löschen Sie nach der Änderung die Datei `intranetDb.mv.db`, um das neue Passwort anzuwenden.


[NOTE]
====
`application-MACOSX.yml` wird nur verwendet, wenn die Anwendung eine macOS-Umgebung erkennt. Wenn Sie Linux oder Windows verwenden, wird sie ignoriert.
====

[WARNING]
====
Durch das Löschen der Datei `intranetDb.mv.db` werden alle zuvor gespeicherten Daten dauerhaft gelöscht.
====




=== Eine persistente Datenbank konfigurieren

Wenn Sie möchten, dass die Daten dauerhaft gespeichert werden, ändern Sie die Dateien `server/grails-app/conf/application.yml` und
`server/grails-app/conf/application-MACOSX.yml`, um eine persistente Datenbank zu verwenden.

.Hier möchten wir, dass H2 die Daten im Entwicklungsmodus in einer Datei speichert:

[source,yaml]
----
environments:
    development:
        dataSource:
            dbCreate: update        <1>
            url: jdbc:h2:./intranetDb;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE <2>
----

<1> Erstellungsmodus (siehe Grails-GORM-Dokumentation)
<2> `intranetDb`: Basisname der Datei, die die Daten enthält

=== Erzeugen einer JAR-Datei für Tomcat

.Verwenden Sie den Task assemble anstelle von bootRun:

[source,bash]
----
$ ./gradlew server:assemble
----
Die erstellte JAR-Datei (z. B. `server-0.6.jar`) befindet sich unter `server/build/libs`.


.Sie können sie auf Ihrem Produktionsserver bereitstellen oder lokal testen

[source,bash]
----
cd server/build/libs
java -jar server-[version].jar   <1>
----
<1> Die Versionsnummer befindet sich in `build.gradle`. Der Standardwert ist 0.6

[TIP]
====
Stellen Sie sicher, dass die Anwendung nicht bereits läuft, wenn Sie eine neue Instanz starten.
====


== Ihre IDE einrichten


Wir empfehlen dringend die Verwendung der neuesten Version der *IntelliJ Ultimate Edition* wegen ihrer umfassenden Unterstützung für *Groovy* und *Grails*.

Wir empfehlen die Installation des *IntelliJ Taack Plugins*, das Sie über den IntelliJ Marketplace https://plugins.jetbrains.com/plugin/20792-taackuiastautocomplete[TaackUiASTAutocomplete] oder direkt aus dem https://github.com/Taack/infra/releases/tag/v0.1[Quellcode-Repository] installieren können.
