=== Infra-Quellcode

https://github.com/Taack/infra

Infra enthält 3 Teilprojekte (wobei `taack-jdbc-common` gemeinsam genutzt wird):

* `client`: Eine Reihe von Kotlin-Dateien, die nach JavaScript transpiliert werden. Dieses Projekt vermeidet das Schreiben von komplexem JavaScript; das Kompilat dieses Projekts wird direkt in die Assets von `taack-ui` kopiert.
* `taack-jdbc-client`: Quellcode des JDBC-Treibers
* `taack-ui`: Quellcode des Grails-Plugins
