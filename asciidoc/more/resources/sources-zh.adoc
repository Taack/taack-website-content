== Github

=== 本网站内容

https://github.com/Taack/taack-website-content

我们使用 asciidoc 格式编写文档，对于本地化翻译，我们在文件名后添加语言后缀。默认语言为英语。`WhyDSL-fr.doc` 为法语版本，`WhyDSL.adoc` 为英语版本（默认版本）。

https://github.com/Taack/taack-autocomplete

=== Infra 源代码

https://github.com/Taack/infra

Infra 包含 3 个子项目（其中 `taack-jdbc-common` 为共享模块）：

* `client`：转译为 Javascript 的一组 Kotlin 文件。该项目避免了编写复杂的 Javascript，其构建产物会直接复制到 `taack-ui` 的静态资源（assets）中。
* `taack-jdbc-client`：JDBC 驱动程序的源代码
* `taack-ui`：Grails 插件源代码
