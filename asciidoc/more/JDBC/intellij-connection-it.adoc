== Aggiunta del driver

Nel pannello del database fare clic sul segno `+`, quindi su `Driver`.

image::intellij-jdbc-driver-configuration.webp[]

L'aggiunta della classe del driver dovrebbe impostare il campo `Class`.

== Aggiunta di una sorgente dati per questo driver

Nel pannello del database fare clic sul segno `+`, quindi su `Data Source`, poi selezionare il driver con il nome appena impostato nel passaggio precedente.

image::intellij-jdbc-dataSource-configuration.webp[]

Utilizzare il proprio nome utente e la password dell'Intranet.

L'URL dovrebbe avere il seguente aspetto:

```
jdbc:taack:localhost:8080/taack
```

Forziamo l'uso della connessione HTTPS per gli host non locali.

== Interrogazione

Dovrebbe essere possibile esplorare le classi di dominio, estrarre dati CSV o eseguire query TQL.
