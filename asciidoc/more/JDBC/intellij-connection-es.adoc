== Añadir el controlador

En el panel de base de datos, haga clic en el signo `+` y luego en `Driver`.

image::intellij-jdbc-driver-configuration.webp[]

Al añadir la clase del controlador se debería establecer el campo `Class`.

== Añadir un origen de datos para este controlador

En el panel de base de datos, haga clic en el signo `+`, luego en `Data Source` y seleccione el controlador con el nombre que acaba de configurar en el paso anterior.

image::intellij-jdbc-dataSource-configuration.webp[]

Utilice su nombre de usuario y contraseña de la Intranet.

La URL debería tener el siguiente aspecto:

```
jdbc:taack:localhost:8080/taack
```

Forzamos el uso de conexión HTTPS para los hosts no locales.
