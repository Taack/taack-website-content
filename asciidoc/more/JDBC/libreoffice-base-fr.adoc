== Configurer LibreOffice pour utiliser le JDK 17

Cliquez sur l'outil `Tools` > `Options`, puis dans la boîte de dialogue *Options - LibreOffice - User Data*, cliquez sur `LibreOffice` > `Advanced` dans l'arborescence.

La case `Use a Java runtime environment` doit être cochée, et vérifiez qu'un JRE version 17 est détecté.

Si ce n'est pas le cas, installez Java 17 et répétez le processus. Vous pouvez cliquer sur le bouton `Add` et suivre la procédure s'il n'est pas détecté mais que vous savez qu'il est installé.

.Java 17 est détecté et sélectionné
image::lo-java17-conf.webp[]

Cliquez sur le bouton `Apply` ou `Ok`.

== Ajouter le pilote Jar

Téléchargez https://github.com/Taack/infra/releases/tag/v0.1[taack-jdbc-client-0.2-SNAPSHOT-all.jar]

Revenez à la boîte de dialogue avancée.

Cliquez sur `Class Path...`, dans la boîte de dialogue, cliquez sur `Add Archive...`, puis sélectionnez le fichier que vous avez téléchargé.

.Pilote ajouté à l'environnement d'exécution
image::lo-java17-driver-conf.webp[]

Cliquez sur le bouton `Ok`.

== Créer un fichier LibreOffice Base

Ouvrez #LibreOffice#, cliquez sur `Base Database`

=== Sélectionner JDBC

.Étape 1 : Sélectionner JDBC
image::lo-base-databaseWizard-1.webp[]

Cliquez sur le bouton `Next`.

=== Entrer l'emplacement du pilote dans le Jar

jdbc : `taack:localhost:8080/taack`

Remplacez localhost et le port par l'URL et le port de votre instance.

Classe du pilote JDBC : `taack.jdbc.client.TaackDriver`

.Étape 2 : Chaîne de connexion du pilote
image::lo-base-databaseWizard-2.webp[]

=== Définir le nom d'utilisateur

Le `User name` doit être un utilisateur actif de votre application Intranet (avec `ROLE_ADMIN` ou `ROLE_JDBC_ADMIN`).

Voir https://github.com/Taack/infra/blob/main/taack-ui/grails-app/controllers/taack/support/TaackJdbcController.groovy[la classe TaackJdbcController].

image::lo-base-databaseWizard-3.webp[]

Cliquez sur le bouton `Finish`, puis définissez un nom de fichier.

== Utilisation dans Base

Ouvrez le fichier enregistré à l'étape précédente et saisissez votre mot de passe lorsque vous y êtes invité.

.Tables lues par le pilote
image::lo-base-tables-screenshot.webp[]

Cliquez sur le bouton Queries, puis sur `Create Query in SQL View`

WARNING: N'utilisez pas l'assistant (wizard). L'Intranet utilise le langage TQL pour interroger les données, LibreOffice ne connaît pas ce langage.

image::lo-base-queries-screenshot.webp[]

Avant de pouvoir saisir des requêtes, cliquez sur `Run SQL Command directly`

image::lo-base-queries-designer-screenshot.webp[]

Maintenant, vous pouvez saisir vos requêtes TQL...

Voir link:taack-jdbc-driver-fr.adoc#_tql_queries[Requêtes TQL].
