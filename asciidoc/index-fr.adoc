== Du code à l'écran

Un formulaire tient en quelques lignes de Groovy. Les champs sont des symboles générés à partir de votre classe (`username_`), vérifiés par le compilateur ; les contraintes deviennent des messages d'erreur traduits.

[.home-split]
--
[source,groovy]
----
def form() {
    DslSampleUser u = new DslSampleUser()
    taackUiService.show(new UiBlockSpecifier().ui {
        modal {
            form createForm(u, {
                row {
                    col {
                        section 'User', {
                            field u.username_
                            field u.firstName_
                            field u.lastName_
                        }
                    }
                    col {
                        section 'Details', {
                            field u.age_
                            field u.birthday_
                            field u.city_
                            field u.status_
                            field u.enabled_
                        }
                    }
                }
                formAction this.&saveForm as MC
            })
        }
    })
}
----

== Fonctionnalités

[.home-card]
====
icon:shield[]

*Sécurité par champ*

Les objets sont affichés et modifiés selon les droits de l'utilisateur sur *chaque champ*. Les liens et actions de formulaire que l'utilisateur ne peut pas exécuter sont automatiquement masqués.

link:doc/UserGuide/Security.adoc[Sécurité →]
====

[.home-card]
====
icon:file-pdf-o[]

*Un seul DSL, tous les formats*

La même description génère du *HTML*, du *PDF*, des *e-mails* et du *CSV*.

link:doc/DSLs/block-printable-dsl.adoc[DSL d'impression →]
====

[.home-card]
====
icon:language[]

*Traduit et validé*

Les libellés proviennent des fichiers i18n, et les erreurs de validation sont traduites sans code supplémentaire.

link:doc/DSLs/form-dsl.adoc#_form_validation[Validation de formulaire →]
====

[.home-card]
====
icon:table[]

*Filtrer, trier, paginer*

Des tableaux et des filtres sans écrire de requêtes ni conserver de données en session.

link:doc/DSLs/filter-table-dsl.adoc[DSL de filtre et de tableau →]
