=== TQL e TDL incorporati in AsciiDoc

Intercom supporta documenti che incorporano presentazioni reveal.js e TQL con TDL. Vedere https://github.com/Taack/infra/releases/tag/v0.5.2[la pagina di download di taack-jdbc-client-1.0-SNAPSHOT-all]

.Esempio di tabella
====
[[tql_tdl]]
.TQL e TDL (Taack Display Language)
[source,sql]
----
select                              <1>
    u.rawImg,
    u.username,
    u.manager.username as manager
from User u
where u.dateCreated > '2024-01-01' and
    u.manager.username = 'admin';
--                                  <2>
table rawImg as "Pic",
      username as "Name",
      manager as "Manager"

----

<1> TQL (Taack Query Language), una sorta di sottoinsieme di HQL
<2> TDL (Taack Display Language), indica come visualizzare i dati interrogati.

.Esempio di diagramma
====
[[tql_tdl]]
.TQL e TDL (Taack Display Language)
[source,sql]
----
select
    u.businessUnit,
    u.subsidiary,
    count(u.id) as counter
from User u
group by u.businessUnit;
--
barchart counter as "Counter"

----
