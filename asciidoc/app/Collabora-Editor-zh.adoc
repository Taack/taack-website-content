== 用途

扩展 Crew 应用中的附件控制器（`Attachment` Controller）。

支持使用 https://www.collaboraonline.com/[Collabora Online] 编辑办公文档。所有附件均可在线编辑。

== 角色

* `ROLE_TEMPLATE_ADMIN`：允许用户创建新模板以用于创建新附件。

== 安装并运行 Collabora CODE Docker 镜像

.启动 Docker
[source,bash]
----
sudo systemctl restart docker
----

.安装 Collabora CODE
[source,bash]
----
sudo docker pull collabora/code:latest
----

.运行 Collabora CODE
[source,bash]
----
sudo docker run --privileged --network host -e "username=test" -e "password=test"  -e "extra_params=--o:ssl.enable=false" -p 9980:9980 collabora/code:latest   <1>
----

<1> 仅出于测试目的，我们禁用了 SSL 并设置了简单的用户名和密码。如果 Collabora 运行在另一台服务器上，则不需要 `--network host`。

.测试服务是否已启动
[source,bash]
----
$ LANG=C wget http://localhost:9980/
--2025-02-18 22:35:56--  http://localhost:9980/
Resolving localhost (localhost)... ::1, 127.0.0.1
Connecting to localhost (localhost)|::1|:9980... connected.
HTTP request sent, awaiting response... 200 OK

    The file is already fully retrieved; nothing to do.
----

== 克隆并链接 `editor-collabora` 仓库

[source,bash]
----
$ git clone https://github.com/Taack/collabora-editor.git
----

== 内网（Intranet）配置

[source,yaml]
----
collabora.url: http://127.0.0.1:9980/     <1>
----

<1> 将 IP 地址替换为服务器的 DNS 名称。
