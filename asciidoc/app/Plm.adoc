== Purpose

Manage FreeCAD model sharing and linear versioning. This app shows the framework capabilities. Very few line of code describe the user interface and manage persistent data. We can view this application as a small PLM (Product Lifecycle Management) for FreeCAD.

== Roles

* `ROLE_ADMIN`
* `ROLE_PLM_USER`

See link:Crew.adoc#_purpose[configure roles in Crew] to add the role into your Intranet

== Server Installation


=== Configure the PLM Server

If you want just an overview, you can download the demo server, with default configuration, go directly in <<_launch_server_binaries>>.

Here are the step by step commands:

.Clone the Intranet repository
[source,bash]
----
git clone https://github.com/Taack/intranet.git
OR
git clone git@github.com:Taack/intranet.git
----

.Go to `app` folder
[source,bash]
----
cd intranet/app
----

.Clone the PLM repository
[source,bash]
----
git clone https://github.com/Taack/plm.git
OR
git clone git@github.com:Taack/plm.git
----

From here, you can build the server or run it. Change current directory to the intranet folder and either:

.Build the server binaries (for production environment)
[source,bash]
----
./gradlew bootJar
----

.Launch the server (for development environment)
[source,bash]
----
./gradlew bootRun
----

=== Launch Server Binaries

Demo version is available here: https://github.com/Taack/plm/releases[Taack PLM releases], download `server-0.6.jar`

If you choose to build the server binaries, go to :

[source,bash]
.Launch the server
----
java -jar server/build/libs/server-0.6.jar
----

==== Server Arguments

See `server/grails-app/conf/application.yml` for a list of available options

Options to the server can be passed this way:

[source,bash]
.Combining Options
----
java -DOption1=Value1 -DOption2=Value2 ... -jar server-0.3.jar
----

===== Options

* Path the Intranet store its files: `-Dintranet.root=/home/test/someDir`
* Server port: `-Dserver.port=9444`
* Database url: `-DdataSource.url='jdbc:h2./prodDb2;LOCK_TIMEOUT=10000;DB_CLOSE_ON_EXIT=FALSE'`
* Dot exe path: `-Dexe.dot.path=/somePath...`

== Usage

=== Connect to the PLM

.Connect to the PLM
image::fc-connect-plm.webp[]

<1> Server URL (with a trailing `/`)
<2> Username
<3> Password
<4> Directory where downloaded parts will sit (make sure it is exclusively reserved for parts from the PLM)
<5> Click Connect, wait for `Connected` to appear

=== Uploading Parts

Clicking on the `Upload` button (or `Ok`) in the `Check-in` tab will upload the file into your Intranet. The Intranet will create a preview, this process might take time.

.Uploading to the PLM
image::freecad-plm.webp[]

=== Search for Parts

Then you can search for parts:

.Search for Parts
image::fc-search-plm.webp[]

<1> Click on `Search Part` tab
<2> Search Part
<3> Top assemblies only (parts that do not belong to another part)
<4> Click to open a dialog box with details
<5> Preview of the part
<6> Checkin, download the model locally and lock the file on the server so no one can upload a new version until you upload a new version
<7> Download the model locally, in read-only mode
<8> Close the window

=== Manage Uploaded Parts

.Manage Uploaded Parts
image::freecad-plm-2.webp[]

<1> Clicking on `Checkin` will lock the part for you to edit, and load the part into FreeCAD. Then, when you upload the part, your new changes will be added to the part history, and the part will be unlocked.
<2> Clicking on `Download Read-Only` will download the part to your computer and open it in FreeCAD. You will not be able to upload changes to this part, unless you duplicate it.

=== Download Read-Only

Notice the `READ_ONLY` in the main Part ID field. If you attempt to upload it via the `Check-in` tab, an error message will remind you that the part is read-only. You will have to duplicate the part to upload a new version.

.Download Read-Only
image::fc-download-only-plm.webp[]

<1> Model hierarchy
<2> Notice the `READ_ONLY` keyword
<3> The 3D model

=== Duplicating Parts

To upload a Read-Only part, you must duplicate it. You can also duplicate a part that you checked in if you want to fork the model.

.Duplicating Parts
image::fc-duplicate-plm.webp[]

<1> Choose how you want to duplicate the model, and click on `Duplicate History` to duplicate the model

This will create a new part on the server, and a link is maintained between the two parts:

.Duplicated Parts on the Server
image::freecad-taack-plm-server-part-details-duplicated.webp[]

<1> Duplicated Parts tab
<2> The cloned part
<3> View the hierarchy graph of this part

.Part List
