=== 在 AsciiDoc 中内联 TQL 和 TDL

Intercom 支持在文档中内联 reveal.js 幻灯片以及带有 TDL 的 TQL。请参阅 https://github.com/Taack/infra/releases/tag/v0.5.2[taack-jdbc-client-1.0-SNAPSHOT-all 下载页面]

.表格示例
====
[[tql_tdl]]
.TQL 与 TDL（Taack Display Language，Taack 显示语言）
[source,sql]
----
select                              <1>
    u.rawImg,
    u.username,
    u.manager.username as manager
from User u
where u.dateCreated > '2024-01-01' and
    u.manager.username = 'admin';
--                                  <2>
table rawImg as "Pic",
      username as "Name",
      manager as "Manager"

----

<1> TQL（Taack Query Language，Taack 查询语言），类似于 HQL 的子集
<2> TDL（Taack Display Language，Taack 显示语言），指定如何展示查询到的数据。

.图表示例
====
[[tql_tdl]]
.TQL 与 TDL（Taack Display Language，Taack 显示语言）
[source,sql]
----
select
    u.businessUnit,
    u.subsidiary,
    count(u.id) as counter
from User u
group by u.businessUnit;
--
barchart counter as "Counter"

----
