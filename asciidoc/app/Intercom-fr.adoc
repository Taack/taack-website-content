=== TQL et TDL intégrés dans AsciiDoc

Intercom prend en charge l'intégration de présentations reveal.js et de requêtes TQL avec TDL directement dans la documentation. Voir https://github.com/Taack/infra/releases/tag/v0.5.2[la page de téléchargement de taack-jdbc-client-1.0-SNAPSHOT-all]

.Exemple de tableau
====
[[tql_tdl]]
.TQL et TDL (Taack Display Language)
[source,sql]
----
select                              <1>
    u.rawImg,
    u.username,
    u.manager.username as manager
from User u
where u.dateCreated > '2024-01-01' and
    u.manager.username = 'admin';
--                                  <2>
table rawImg as "Pic",
      username as "Name",
      manager as "Manager"

----

<1> TQL (Taack Query Language), une sorte de sous-ensemble de HQL
<2> TDL (Taack Display Language), indique comment afficher les données requêtées.

.TQL et TDL (Taack Display Language)
[source,sql]
----
select
    u.businessUnit,
    u.subsidiary,
    count(u.id) as counter
from User u
group by u.businessUnit;
--
barchart counter as "Counter"
