=== TQL und TDL eingebettet in AsciiDoc

Intercom unterstützt Dokumente mit eingebetteten reveal.js-Präsentationen sowie TQL mit TDL. Siehe https://github.com/Taack/infra/releases/tag/v0.5.2[taack-jdbc-client-1.0-SNAPSHOT-all Download-Seite]

.Tabellenbeispiel
====
[[tql_tdl]]
.TQL und TDL (Taack Display Language)
[source,sql]
----
select                              <1>
    u.rawImg,
    u.username,
    u.manager.username as manager
from User u
where u.dateCreated > '2024-01-01' and
    u.manager.username = 'admin';
--                                  <2>
table rawImg as "Pic",
      username as "Name",
      manager as "Manager"

----

<1> TQL (Taack Query Language), eine Art HQL-Teilmenge
<2> TDL (Taack Display Language), gibt an, wie abgefragte Daten angezeigt werden sollen.

[[tql_tdl]]
.TQL und TDL (Taack Display Language)
[source,sql]
----
select
    u.businessUnit,
    u.subsidiary,
    count(u.id) as counter
from User u
group by u.businessUnit;
--
barchart counter as "Counter"

----
